## 通用红线
- 红线一：绝不写假数据。采集失败就是失败，不替 0。
- 红线二：绝不把网络错误当业务状态（下架 / 违规要有明确特征）。
- 红线三：绝不闪黑框、绝不崩溃、绝不让单任务卡死整轮。
- 红线四：统计只信快照差值，累计值回退用高水位。
