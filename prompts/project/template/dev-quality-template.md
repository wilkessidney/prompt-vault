## 五、失败 / 异常列表
- 仅放临时失败与环境错误，不放明确下架商品
- 支持单 / 批量重试、忽略、删除；重试成功自动移出；明确终止则转入终止列表

## 六、运行日志
- 持久化到数据库，重启不丢；字段：时间 / 级别 / 来源 / 实体 / 摘要 / 完整详情
- 界面：按级别 / 来源筛选、刷新、清空（二次确认）、导出 CSV、双击看完整异常并可复制
- 失败展示真实异常而非「失败」二字

## 七、稳定性与安全（红线）
- 不写死个人凭据；敏感信息脱敏（日志不输出 Cookie / Webhook 完整值）
- 事务写入防半条记录；图片 / 请求 / 通知均设超时
- 任何失败不让 GUI 崩溃；关闭时释放浏览器与临时进程
