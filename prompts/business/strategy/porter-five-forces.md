## 输入
- 行业：{{行业名 + 阶段}}
- 业务定位：{{在行业中的位置}}
- 评估目标：{{进入 / 退出 / 定位 / 竞争}}

## 波特五力结构
### 1. 行业内竞争（现有对手）
- 主要玩家：{{3-10 家 + 市占率}}
- 竞争强度：高 / 中 / 低
- 关键竞争维度：{{价格 / 功能 / 服务 / 渠道 / 品牌}}
- 退出壁垒：{{高 / 中 / 低}}
- 增长率：{{行业增长越快竞争越温和}}
- 固定成本：{{越高竞争越激烈}}

### 2. 新进入者威胁
- 进入壁垒：{{规模经济 / 品牌 / 资本 / 转换成本 / 政府}}
- 预期报复：{{现有玩家的反应}}
- 进入成本：{{高 / 中 / 低}}
- 行业吸引力：{{对新进入者}}

### 3. 替代品威胁
- 替代品：{{其他满足相同需求的方案}}
- 替代品的相对价值 / 价格：{{对比}}
- 替代品趋势：{{上升 / 稳定 / 下降}}
- 转换成本：{{用户从替代品转回的难度}}

### 4. 供应商议价能力
- 主要供应商：{{类型 + 数量}}
- 议价能力：高 / 中 / 低
- 关键因素：{{供应商集中度 / 转换成本 / 前向整合威胁}}
- 应对：{{多供应商 / 长期合同 / 自研}}

### 5. 买家议价能力
- 主要买家：{{类型 + 集中度}}
- 议价能力：高 / 中 / 低
- 关键因素：{{买家集中度 / 信息透明度 / 转换成本 / 价格敏感度}}
- 应对：{{差异化 / 锁定 / 增值服务}}

### 6. 综合判断
- 行业吸引力：{{高 / 中 / 低}}
- 关键力量：{{5 力中最强的是哪个}}
- 战略含义：{{对业务的影响}}

### 7. 战略选项
- 定位选择：{{差异化 / 成本领先 / 聚焦}}
- 价值链重构：{{上下游整合 / 渠道创新}}
- 蓝海机会：{{避开红海的方式}}

### 8. 行动建议
- 短期：{{应对最强力量}}
- 中期：{{构建壁垒}}
- 长期：{{重塑行业结构}}

## 写作硬规则
- **每力都有数据支撑**（不拍脑袋）
- 玩家数量给具体数字
- 关键维度基于实际竞争
- 战略选项有取舍
- 行动建议有具体动作 + 时间表
