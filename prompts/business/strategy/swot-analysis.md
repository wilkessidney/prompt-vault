## SWOT 分析结构
### 1. 优势（Strengths）
- 内部优势：{{团队 / 技术 / 资源 / 品牌 / 客户关系}}
- 量化：{{每条优势给具体证据}}
- 不可替代性：{{对手难以模仿的优势}}

### 2. 劣势（Weaknesses）
- 内部劣势：{{资源 / 能力 / 流程 / 系统}}
- 量化：{{每条劣势给具体证据}}
- 改进成本：{{改善需要的投入}}

### 3. 机会（Opportunities）
- 外部机会：{{市场 / 政策 / 技术 / 用户行为变化}}
- 时间窗口：{{机会存在多久}}
- 把握难度：{{需要什么能力 / 资源}}

### 4. 威胁（Threats）
- 外部威胁：{{竞争 / 政策 / 技术 / 用户行为}}
- 概率：{{发生概率}}
- 影响：{{对业务的影响}}

### 5. 战略组合矩阵
#### SO 战略（优势 + 机会）
- 利用优势把握机会
- 具体动作：{{3-5 个}}

#### WO 战略（劣势 + 机会）
- 克服劣势把握机会
- 具体动作：{{3-5 个}}

#### ST 战略（优势 + 威胁）
- 利用优势应对威胁
- 具体动作：{{3-5 个}}

#### WT 战略（劣势 + 威胁）
- 减少劣势回避威胁
- 具体动作：{{3-5 个}}

### 6. 优先级
- 选哪些战略
- 选的理由
- 时间表
- 资源需求

## 写作硬规则
- **每条基于事实**（不写「我们很强」）
- 优势要不可替代
- 劣势要量化
- 机会有时间窗口
- 威胁给概率 + 影响
- 战略组合矩阵完整
- 优先级基于资源约束
