## 输入
- 团队 / 公司：{{名 + 阶段 + 规模}}
- 公司战略：{{本季度 3 个战略目标}}
- 团队职责：{{核心职责}}
- 历史 OKR：{{上季度 OKR + 完成度}}

## OKR 规划结构
### 1. 公司 OKR（对齐上层）
- 公司本季度 O1 / O2 / O3
- 每个 O 的 KR（2-4 个）

### 2. 团队 OKR（≤5 个 O）
#### O1 设定（基于战略对齐）
- O1 的清晰陈述：{{动词 + 对象 + 结果}}
- 与公司哪个 O 对齐
- 挑战度：{{0.6-0.7 完成度为最佳}}

#### O1 的 KR（3-4 个）
- KR1：{{具体 + 可量化 + 有挑战 + 可验证}}
- KR2：{{同上}}
- KR3：{{同上}}
- KR4：{{可选项}}

#### O2 设定
- O2 的清晰陈述
- 与公司哪个 O 对齐

#### O2 的 KR（3-4 个）
...

### 3. 跨团队依赖
- 与其他团队的协同 OKR
- 共享 KR
- 依赖关系

### 4. OKR 节奏
- 周会：进度同步（KR 信心指数）
- 月度：1:1 + 月度评审
- 季度中：评分 + 调整
- 季度末：复盘 + 下季度规划

### 5. 评分机制
- 信心指数：{{0-1}}
- 季度末评分：{{0.0-1.0}}
  - 1.0：超额完成
  - 0.7：完成目标（最佳）
  - 0.3：有所进展
  - 0.0：未完成
- 评分不是为了考核，是为反思

### 6. 沟通与公开
- OKR 全员公开
- 周会公示信心指数
- 月度报告
- 季度评审公开

## 写作硬规则
- **每个 O 是方向性，每个 KR 是量化**
- O 不超过 5 个，KR 每个 O 不超过 4 个
- KR 必须可量化、可验证、有挑战
- 不要把 KR 写成任务清单（不是 todo）
- 不要承诺 OKR 100% 完成（应是挑战性目标）
- 信心指数定期更新

## 自检
- [ ] O 是否方向性
- [ ] KR 是否量化 + 可验证 + 有挑战
- [ ] O 数量是否 ≤5
- [ ] KR 数量是否每个 ≤4
- [ ] 是否与公司 OKR 对齐
- [ ] 是否全公司公开
