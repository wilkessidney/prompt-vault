## 输出

### 1. 结构完整性检查
表格：必备条款 | 是否存在 | 缺失风险

### 2. 关键风险条款（按严重度排序）
每条格式：
```
【条款位置】第 X 条
【原文要点】
【风险】对我方的具体影响（量化：金额/责任范围/时间）
【谈判优先级】高/中/低
【修改建议】具体的替代表述
```

**重点排查项**：
| 条款类型 | 要检查什么 |
|----------|-----------|
| 付款 | 付款节点、账期、逾期违约金、发票与税、是否可抵扣 |
| 交付与验收 | 验收标准是否客观、验收期限、视为验收条款、多次整改的权利限制 |
| 违约责任 | 违约金是否过高/不对等、是否有责任上限、间接损失是否排除 |
| 知识产权 | 交付物归属、背景知识产权、是否需要授权、衍生权利 |
| 保密 | 范围、期限、例外、违约后果 |
| 竞业限制 | 范围、期限、地域、是否有补偿 |
| 不可抗力 | 定义范围、后果、是否包含疫情/政策变化 |
| 终止条款 | 任意解除权、提前通知期、终止后的结算与过渡 |
| 争议解决 | 管辖法院/仲裁机构、适用法、成本承担 |
| 数据合规 | 个人信息处理、跨境传输、安全责任 |
| 责任限制 | 上限金额、是否覆盖间接损失、是否有例外情形 |

### 3. 不对等条款识别
列出明显偏向对方的条款（如：对方有任意解除权而我方没有、违约金单方面适用于我方）。

### 4. 谈判策略
- **必须争取**（不可让步）：
- **可以交换**（让步条件）：
- **可以放弃**（影响小）：
按优先级给出 3 轮谈判的话术与让步节奏。

### 5. 待确认事项
需要向业务方或律师确认的问题清单。

## 硬规则
- **不要声称这是法律意见**。涉及重大金额、新型业务、跨境、劳动纠纷时，明确建议请律师。
- 不要凭空编造法条。引用具体法律规定时，标注「需核实最新有效版本」。
- 空白条款、附件缺失、「另行约定」这类未完成内容必须单独列出，这是最常见的大坑。
