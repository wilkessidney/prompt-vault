- 产品：{{产品名 + 类型}}
- 收集的数据：{{数据类型 + 收集方式}}
- 适用法规：{{GDPR / 中国个保法 / CCPA / 行业法规}}

## 隐私政策结构
### 1. 概述
- 一句话讲清我们怎么对待用户数据
- 政策生效日期
- 适用范围

### 2. 我们收集什么
- 注册信息：{{邮箱 / 手机 / 第三方登录}}
- 使用信息：{{行为日志 / 设备信息 / Cookie}}
- 主动提供：{{用户上传 / 评论 / 设置}}
- 敏感信息：{{明确定义 + 单独同意}}

### 3. 为什么收集
- 提供服务：{{必要}}
- 改善产品：{{分析 + 优化}}
- 个性化：{{推荐 + 设置}}
- 安全：{{风控 + 反欺诈}}
- 合规：{{法律义务}}

### 4. 怎么使用
- 自动化处理：{{明确告知}}
- 人工处理：{{明确告知 + 同意}}
- 个性化决策：{{单独同意 / 可拒绝}}

### 5. 是否共享
- 共享给谁：{{明确列出每个第三方}}
- 为什么共享：{{每个具体目的}}
- 共享什么：{{每个具体数据}}
- 用户是否可拒绝：{{每个共享场景}}

### 6. 是否跨境
- 跨境目的地：{{具体国家 / 地区}}
- 跨境依据：{{标准合同 / 充分性决定 / 同意}}
- 数据保护：{{加密 + 访问控制}}

### 7. 存储期限
- 不同数据类型：{{不同期限}}
- 决定期限的因素
- 过期处理：{{删除 / 匿名化}}

### 8. 安全措施
- 技术措施：{{加密 / 访问控制 / 监控}}
- 组织措施：{{培训 / 制度 / 应急}}
- 安全事件响应

### 9. 用户权利
- 知情权：{{明确告知}}
- 访问权：{{数据副本}}
- 更正权：{{修改错误}}
- 删除权：{{条件 + 流程}}
- 限制处理权：{{暂停处理}}
- 拒绝权：{{针对特定处理}}
- 数据可携权：{{格式 + 交付方式}}
- 撤回同意：{{同等于给出的同意}}

### 10. 未成年人
- 是否有未成年人用户
- 是否单独同意
- 如何识别未成年人

### 11. 政策变更
- 变更通知：{{提前通知}}
- 重大变更：{{重新同意}}
- 历史版本：{{保留可查}}

### 12. 联系我们
- 数据保护负责人：{{姓名 + 联系方式}}
- 处理反馈的流程
- 投诉渠道：{{监管机构}}

## 写作硬规则
- **法律语言 + 用户友好语言双版本**（建议双层呈现）
- 每个数据收集都给具体目的
- 第三方共享逐个列清
- 用户权利给具体行使方式
- 跨境传输给法律依据
- 安全措施可被验证
