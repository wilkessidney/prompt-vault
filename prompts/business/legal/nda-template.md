## 输入
- 场景：{{合作洽谈 / 投资沟通 / 雇佣 / 供应商评估}}
- 双方：{{披露方 + 接收方}}
- 保密范围：{{技术 / 商业 / 客户 / 财务}}
- 期限：{{保密期 + 协议期}}
- 适用法律：{{中国 / 美国 / 其他}}

## NDA 结构
### 1. 定义
- 保密信息：{{定义 + 范围 + 例外}}
- 披露方：{{提供信息方}}
- 接收方：{{接收信息方}}
- 关联实体：{{母 / 子 / 兄弟公司}}
- 代表：{{员工 + 顾问 + 代理}}

### 2. 保密义务
- 不披露：{{给第三方}}
- 不使用：{{超出协议目的外使用}}
- 保护措施：{{与保护自有信息同等 / 合理措施}}
- 告知人员：{{仅告知需要知道的人}}

### 3. 允许的披露
- 法律要求：{{法院 / 监管机构要求时}}
- 已公开信息：{{非因接收方原因公开}}
- 第三方合法提供：{{有权披露的第三方}}
- 独立开发：{{不基于保密信息}}

### 4. 保密期限
- 协议期：{{具体年数}}
- 保密义务期：{{协议期 + N 年 / 永久}}
- 商业秘密：{{永久保密}}

### 5. 信息返还
- 终止时：{{返还 / 销毁}}
- 确认：{{书面确认}}
- 例外：{{法定保留的备份}}

### 6. 不构成其他关系
- 不构成合作
- 不构成许可
- 不构成雇佣
- 不构成代理

### 7. 无担保
- 保密信息「按现状」提供
- 不担保准确性 / 完整性

### 8. 违约责任
- 实际损失：{{直接损失}}
- 违约赔偿：{{具体金额或合理估算}}
- 禁令救济：{{可申请禁令}}
- 律师费：{{败诉方承担}}

### 9. 协议终止
- 终止条件：{{协商 / 违约 / 期限届满}}
- 终止后义务：{{保密义务继续}}

### 10. 其他条款
- 适用法律
- 争议解决：{{协商 / 仲裁 / 法院}}
- 通知方式
- 修改：{{书面 + 双方}}
- 可分割性
- 完整协议

## 写作硬规则
- **条款清晰具体**（不写「合理措施」之类的模糊）
- 保密范围明确定义（避免泛化）
- 例外条款不可缺（否则对方有顾虑）
- 期限具体明确
- 违约责任有金额或估算方式
- 争议解决明确

## 自检
- [ ] 保密范围是否明确
- [ ] 例外条款是否完整
- [ ] 期限是否具体
- [ ] 违约责任是否明确
- [ ] 争议解决是否清晰
