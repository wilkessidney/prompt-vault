## 输入
- 产品：{{产品名 + 类型}}
- 商业模式：{{订阅 / 一次性 / Freemium / 广告}}
- 用户类型：{{B2C / B2B / 混合}}
- 特殊考虑：{{跨境 / 行业监管 / 用户生成内容}}

## 服务条款结构
### 1. 接受条款
- 用户点击 / 注册即接受
- 不接受的方式：{{退出流程}}

### 2. 服务说明
- 服务范围：{{明确}}
- 服务变更：{{保留变更权利 + 通知}}
- 服务可用性：{{SLA（如有）+ 不可用时补救}}

### 3. 用户账户
- 注册要求：{{年龄 / 真实信息}}
- 账户安全：{{用户责任 + 我们的保护}}
- 账号暂停：{{条件 + 通知 + 申诉}}

### 4. 用户行为规范
- 禁止行为：{{违法 / 骚扰 / 滥用 / 商业使用（除非允许）}}
- 用户生成内容：{{归属 + 我们的使用许可 + 删除权利}}
- 内容审查：{{是否主动审查 + 接到投诉后的处理}}

### 5. 知识产权
- 我们的 IP：{{产品 / 商标 / 内容}}
- 用户授权：{{使用产品所必需的}}
- 反馈使用：{{用户给我们的反馈我们可使用}}

### 6. 付费与退款
- 价格：{{明确 + 变更通知}}
- 支付：{{方式 + 时间}}
- 续费：{{自动续费 + 提前通知 + 取消方式}}
- 退款：{{条件 + 时限 + 流程}}
- 税费：{{谁承担}}

### 7. 免责声明
- 服务按「现状」提供
- 不保证无中断 / 无错误
- 不承担间接损失
- 不承担数据丢失（建议用户备份）

### 8. 责任限制
- 责任上限：{{金额或服务费}}
- 不承担：{{特定类型损失}}
- 例外：{{不可排除的责任}}

### 9. 终止
- 用户终止：{{随时 + 流程}}
- 我们终止：{{条件 + 通知 + 后果}}
- 终止后果：{{数据保留 / 删除 / 费用}}

### 10. 争议解决
- 适用法律：{{明确}}
- 管辖：{{法院 / 仲裁}}
- 争议处理流程：{{先协商 / 再仲裁 / 最后诉讼}}

### 11. 其他
- 转让：{{可否}}
- 通知：{{方式 + 视为送达}}
- 完整协议：{{与其他文件关系}}
- 可分割性：{{部分无效不影响其他}}

## 写作硬规则
- **条款清晰可读**（避免法律黑话堆砌）
- 用户权利必须明确（不能全是免责）
- 责任限制合理（不能完全推卸）
- 终止条件明确（避免模糊）
- 争议解决明确（不模糊）
- 符合目标市场法律

## 自检
- [ ] 条款是否清晰可读
- [ ] 用户权利是否明确
- [ ] 责任限制是否合理
- [ ] 终止条件是否明确
- [ ] 争议解决是否明确
