- 产品：{{产品名 + 业务类型}}
- 适用法规：{{GDPR / 中国个保法 / CCPA / HIPAA / 行业法规}}
- 用户范围：{{国内 / 国际 / 特定地区}}
- 数据范围：{{个人数据 / 敏感数据 / 儿童数据}}

## 自查结构
### 1. 数据清单
- 收集的数据类型：{{逐项列出}}
- 收集方式：{{主动 / 被动 / 第三方}}
- 收集目的：{{逐项对应}}
- 法律依据：{{同意 / 合同 / 法定 / 必要}}

### 2. 用户权利
- 知情权：是否清晰告知
- 访问权：是否提供访问入口
- 更正权：是否提供修改入口
- 删除权：是否提供删除入口
- 限制处理权：是否提供暂停入口
- 数据可携权：是否提供导出
- 拒绝权：是否提供拒绝选项
- 撤回同意：是否同等于给予同意

### 3. 同意管理
- 同意获取：是否明确具体
- 同意记录：是否可证明
- 同意撤回：是否容易
- 儿童同意：是否有特殊机制

### 4. 数据处理
- 处理目的：是否最小化
- 处理方式：是否安全
- 自动化决策：是否告知 + 用户可干预
- 用户生成内容：是否有保护机制

### 5. 数据共享
- 第三方清单：是否完整
- 数据处理协议：是否签订
- 跨境传输：是否有法律依据
- 共享范围：是否最小化

### 6. 数据安全
- 加密：传输 + 存储
- 访问控制：最小权限
- 安全监控：是否到位
- 安全事件响应：是否有预案

### 7. 数据保留
- 保留期限：是否明确
- 删除机制：到期限后是否删除
- 匿名化：是否在合适时使用
- 备份：是否安全保留

### 8. 组织与流程
- 数据保护负责人：{{是否指定}}
- 内部培训：员工是否知情
- 合规审计：是否有定期审计
- 文档管理：政策 + 流程是否完整

### 9. 风险评级
- 高风险项：{{列出 + 整改方案}}
- 中风险项：{{同上}}
- 低风险项：{{列出}}
- 整改优先级：{{按风险排序}}

### 10. 整改计划
- 关键整改项
- 时间表
- 资源需求
- 验证方式

## 写作硬规则
- **每项检查必须有具体证据**，不写「已合规」
- 风险评级有标准
- 整改方案有具体动作 + 时间表
- 跨境传输有法律依据
- 数据保留期限有依据
- 安全措施可被验证

## 自检
- [ ] 数据清单是否完整
- [ ] 用户权利是否可行使
- [ ] 同意管理是否规范
- [ ] 数据共享是否有协议
- [ ] 风险是否有整改方案
