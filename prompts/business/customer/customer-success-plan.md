你是客户成功经理。帮我为一个关键客户设计全生命周期成功计划。{{客户 + 合同 + 目标}}

## 输入
- 客户：{{公司名 + 行业 + 规模}}
- 合同：{{金额 / 周期 / 产品}}
- 客户目标：{{用我产品要达成什么}}
- 健康度初始评估：{{基于什么判断}}

## 客户成功计划结构
### 1. 客户目标对齐
- 客户业务目标：{{KPI + 期望达成}}
- 我们能帮助的：{{具体功能 / 服务}}
- 共同 KPI：{{双方共同衡量}}
- 成功标准：{{客户认为成功的标准}}

### 2. 实施计划
- 阶段划分：{{3-5 阶段}}
- 每阶段：{{目标 / 关键动作 / 时间 / 责任人}}
- 关键里程碑：{{明确节点}}
- 风险与缓解：{{已知风险}}

### 3. 价值实现路径
- 首次价值：{{签约后 X 天内达成}}
- 阶段性价值：{{每月 / 每季度}}
- 长期价值：{{年度总结}}

### 4. 健康度监控
- 关键指标：{{使用率 / 活跃用户 / 关键功能使用 / 满意度}}
- 频率：{{实时 / 每周 / 每月}}
- 预警阈值：{{红 / 黄 / 绿}}
- 升级机制：{{黄 → 红的动作}}

### 5. 沟通计划
- 例会：{{每周 / 双周 / 月}}
- 季度评审：{{业务价值回顾}}
- 高层沟通：{{每季度 / 每半年}}
- 危机沟通：{{出现问题的机制}}

### 6. 续约策略
- 续约时机：{{提前 X 个月启动}}
- 续约依据：{{使用数据 + 业务价值}}
- 续约谈判：{{提前 X 个月谈判}}
- 续约激励：{{提前续约优惠 / 加值服务}}

### 7. 扩展机会
- 跨部门：{{扩展到其他部门}}
- 跨产品：{{加购其他产品}}
- 升级：{{从低阶到高阶}}
- 路径规划：{{具体时间表}}

### 8. 风险与应对
- 客户流失风险：{{信号 + 应对}}
- 内部资源风险：{{依赖谁 + 备份}}
- 业务变化风险：{{客户业务变化的应对}}

## 写作硬规则
- **每个目标都要可量化**，避免「满意度高」
- 健康度阈值明确，避免主观
- 沟通频率基于客户类型（高价值高接触）
- 续约提前启动，避免临期被动
- 扩展机会要主动规划
- 风险给具体应对方案

- [ ] 客户目标是否可量化

- [ ] 续约是否提前启动
- [ ] 扩展机会是否主动规划
