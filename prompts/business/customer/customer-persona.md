## 输入
- 产品：{{产品名 + 卖点}}
- 客户分层：{{按角色 / 按行业 / 按规模}}
- 已有材料：{{客户访谈 / 销售线索 / CRM 数据}}

## 客户档案结构
### 1. 基础信息
- 角色：{{职位 + 决策权}}
- 行业 / 公司规模：{{细分行业 + 营收 / 人数}}
- 地理：{{具体区域}}
- 收入范围：{{具体数字}}

### 2. 角色与责任
- 工作内容：{{日常职责}}
- 关键业绩指标：{{KPI + 季度 / 年度目标}}
- 向谁汇报：{{上级 + 协作部门}}
- 痛点：{{工作上最大的 3 个痛点}}

### 3. 决策模式
- 决策权：{{单独 / 联合 / 推荐}}
- 决策周期：{{即时 / 月 / 季度 / 年度}}
- 决策依据：{{数据 / 经验 / 高管意见 / 同行参考}}
- 预算来源：{{自己 / 部门 / 项目 / 高管}}

### 4. 信息渠道
- 行业信息：{{公众号 / 行业报告 / 同行 / 会议}}
- 产品调研：{{G2 / Gartner / 知乎 / 朋友推荐}}
- 同行影响：{{谁的话最管用}}

### 5. 痛点与机会
- 工作痛点：{{3 个具体场景}}
- 这些痛点的影响：{{数字 / 后果}}
- 现有方案：{{用什么解决 / 为什么不够好}}
- 我们的机会：{{什么场景触发他了解我们}}

### 6. 触达与转化路径
- 触发场景：{{何时开始了解我们的方案}}
- 触达渠道：{{公众号 / 朋友圈 / 销售 / 推荐}}
- 决策路径：{{了解 → 评估 → 试用 → 决策 → 推进}}
- 关键异议：{{价格 / 数据安全 / 集成 / 迁移成本}}

### 7. 引言
- 直接引用：≥3 句他在调研中说过的话
- 每句引言后说明：这句话揭示了什么

## 写作硬规则
- **每个档案基于真实调研**，不写「感觉」「印象」
- ≥5 个客户的引用
- 区分「真实行为」vs「自述偏好」
- 决策权明确（避免卖给无决策权的人）
- 引言真实，不编造
- 触达路径基于实际销售数据

## 自检
- [ ] 档案是否基于真实数据
- [ ] 决策权是否明确
- [ ] 触达路径是否基于实际数据
- [ ] 引言是否真实可追溯
