## 测算要求

### 1. 三层市场定义
| 层级 | 定义 | 计算逻辑 | 金额 |
|------|------|----------|------|
| TAM | 理论上所有潜在客户 | | |
| SAM | 你的产品/渠道能触达的 | | |
| SOM | 3-5 年实际可获取的 | | |

### 2. 自下而上测算（主方法）
```
公式：市场 = 客户数量 × 渗透率 × 客单价 × 购买频次

逐项拆解，每项给出：
- 数值
- 数据来源（统计局/行业报告/可比公司财报/调研）
- 可信度（高/中/低）
- 关键假设与假设不成立时的影响
```

### 3. 自上而下校验（交叉验证）
用行业总规模 × 目标细分占比做交叉验证。
若两个方法差异超过 {{50%}}，说明哪里错了，要解释清楚。

### 4. 可比公司参照
表格：可比公司 | 收入规模 | 市占率 | 增长 | 所在市场 | 参照价值

### 5. 敏感性分析
给出乐观/中性/悲观三档，说明各自触发条件：
| 情景 | 关键变量 | 市场规模 | 概率 |

### 6. 增长驱动与抑制因素
- 未来 3-5 年市场增长/萎缩的驱动力
- 天花板在哪，什么时候会触到

## 硬规则
- **禁止直接引用「XX 报告说这个市场有 XX 亿」而不给计算过程**，那是引用不是测算。
- 每个数字必须能追溯到来源。来源不明的数字标注「估算」并说明估算依据。
- 假设要保守。用乐观假设做出来的市场规模没有说服力。
- 明确说明这个测算**没有考虑**什么（如替代市场、出海、政策变化）。
