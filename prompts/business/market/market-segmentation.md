## 输入
- 市场：{{行业 / 赛道}}
- 业务目标：{{聚焦 / 扩张 / 差异化}}
- 已有用户：{{如有}}
- 已有假设：{{细分维度}}

## 市场细分结构
### 1. 细分维度选择
选择 2-3 个核心维度：
- 人口维度：{{年龄 / 性别 / 收入 / 教育 / 地理}}
- 行为维度：{{使用频率 / 购买偏好 / 品牌偏好}}
- 心理维度：{{价值观 / 生活方式 / 个性}}
- 需求维度：{{价格敏感 / 服务依赖 / 创新需求}}

### 2. 细分市场描述
对每个细分市场：
- 命名：{{具体可识别}}
- 大小：{{客户数 + 营收潜力}}
- 增长：{{增长率 + 趋势}}
- 关键需求：{{核心痛点 + 期待}}
- 行为特征：{{购买 / 使用 / 触达}}
- 价值敏感度：{{价格 / 服务 / 品牌}}
- 触达渠道：{{公众号 / 搜索 / 销售 / 社群}}

### 3. 细分市场评估
| 细分市场 | 大小 | 增长 | 竞争 | 我们的适配度 | 优先级 |
|---------|------|------|------|------------|--------|
| 细分 1 | 大 | 高 | 弱 | 高 | P0 |
| 细分 2 | 中 | 中 | 中 | 中 | P1 |
| 细分 3 | 小 | 低 | 弱 | 高 | P2 |

### 4. 目标市场选择（STP）
- 选哪些细分作为目标市场
- 选的理由：{{大小 + 增长 + 适配度 + 竞争}}
- 不选的理由：{{机会成本}}

### 5. 定位
- 对每个目标细分：定位陈述
- 与竞品的差异化
- 核心价值主张
- 品牌调性

### 6. 进入策略
- 优先级：{{P0 / P1 / P2}}
- 进入顺序：{{先入后入}}
- 资源分配：{{比例}}
- 验证指标：{{6 个月内的指标}}

### 7. 营销组合（4P）
- Product：{{产品适配}}
- Price：{{定价}}
- Place：{{渠道}}
- Promotion：{{推广}}

## 写作硬规则
- **每个细分有数据支撑**（不写「大概」「可能」）
- 细分维度互斥（MECE）
- 评估标准明确（避免主观）
- 定位陈述清晰可记忆
- 资源分配基于优先级
- 营销组合 4 个 P 联动

## 自检
- [ ] 细分是否有数据支撑
- [ ] 细分维度是否互斥
- [ ] 评估标准是否明确
- [ ] 定位陈述是否清晰
- [ ] 营销组合是否联动
