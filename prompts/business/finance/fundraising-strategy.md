## 输入
- 公司：{{公司名 + 业务 + 阶段}}
- 当前融资轮次：{{Pre-A / A / B}}
- 融资目标：{{金额 + 用途}}
- 当前估值：{{如有}}
- 历史融资：{{已融 + 投资人}}

## 融资策略结构
### 1. 融资必要性评估
- 是否需要融资：{{跑道 + 增长需求}}
- 不融资的替代方案：{{盈利 / 减少烧钱 / 收入增长}}
- 融资的最佳时机：{{基于里程碑 + 市场窗口}}
- 等待的成本：{{跑道耗尽 / 估值下降}}

### 2. 融资目标
- 融资金额：{{12-18 个月运营资金}}
- 估值预期：{{基于可比公司 + 业绩 + 市场}}
- 稀释比例：{{接受 X% 稀释}}
- 资金用途：{{占比最大的 3 项}}

### 3. 投资人策略
#### 投资人类型选择
- 战略投资人：{{能带来资源 / 客户 / 品牌}}
- 财务投资人：{{带来钱 + 治理经验}}
- 产业资本：{{深度绑定产业}}
- 混合：{{主财务 + 辅战略}}

#### 投资人地图
- 头部机构：{{3-5 家目标}}
- 中部机构：{{5-10 家备选}}
- 天使 / 朋友：{{早期背书}}
- 每家：{{关注赛道 / 投资阶段 / 历史案例 / 决策人}}

### 4. 融资材料
- 路演 PPT：{{10-15 页}}
- 一页纸：{{给快速过目的合伙人}}
- 详细 BP：{{深度 DD 用}}
- 财务模型：{{3 年预测}}
- 团队介绍：{{核心成员}}
- 数据房间：{{合同 / 数据 / 代码}}

### 5. 时间表与节奏
- 准备期：{{X 周：材料 + 内部对齐}}
- 预热期：{{X 周：熟人介绍 + 投资人推荐}}
- 正式路演：{{X 周：密集会议}}
- 决策期：{{X 周：TS 谈判 + DD}}
- 交割期：{{X 周：法律文件 + 打款}}
- 总周期：{{3-6 个月}}

### 6. 谈判策略
- 估值依据：{{可比公司 + 业绩倍数 + 市场}}
- 条款红线：{{董事会 / 保护条款 / 反稀释}}
- 备选方案：{{不只有一家 TS}}
- TS 谈判：{{估值 / 条款 / 时间表}}
- 投后支持：{{期望投资人提供的资源}}

### 7. 风险与应对
- 估值低于预期：{{降低融资金额 / 多投资人联合 / 桥贷}}
- 投资人拒绝：{{调整预期 / 找下家 / 内部加码}}
- 政策 / 市场变化：{{暂停 / 调整金额 / 估值调整}}

## 写作硬规则
- **融资金额有依据**：跑道 + 增长需求
- 估值有可比公司支撑
- 投资人选择有逻辑（不撒网）
- 时间表符合实际（不是 1 个月搞定）
- 谈判红线提前定（不在会议室临时决定）
- 风险给具体应对
