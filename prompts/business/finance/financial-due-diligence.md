## 财务尽调结构
### 1. 公司概况
- 基本信息：{{成立 / 股东 / 治理}}
- 业务模式：{{收入 + 成本 + 利润逻辑}}
- 财务系统：{{ERP / 财务软件 / 内控}}

### 2. 财务报表审阅
#### 资产负债表
- 资产质量：{{现金 / 应收 / 存货 / 固定资产}}
- 负债结构：{{短期 / 长期 / 或有}}
- 净资产：{{实收资本 + 留存}}
- 关键科目异常：{{逐项标注}}

#### 利润表
- 收入确认：{{是否合规}}
- 成本结转：{{是否匹配}}
- 期间费用：{{合理性}}
- 利润质量：{{核心利润 vs 一次性}}

#### 现金流量表
- 经营性现金流：{{是否匹配利润}}
- 投资性现金流：{{用途合理}}
- 融资性现金流：{{资本结构}}

### 3. 收入尽调
- 收入明细：{{按客户 / 产品 / 渠道拆}}
- 收入真实性：{{回款 + 应收账款验证}}
- 收入可持续性：{{客户集中度 + 合同剩余期}}
- 收入政策：{{是否符合会计准则}}

### 4. 成本费用尽调
- 成本结构：{{直接 / 间接}}
- 费用合理性：{{销售 / 管理 / 研发}}
- 关联方交易：{{是否公允}}

### 5. 税务尽调
- 税种：{{增值税 / 所得税 / 其他}}
- 税务合规：{{申报 + 缴纳}}
- 税务风险：{{潜在补税 + 罚款}}
- 税收优惠：{{是否合规享受}}

### 6. 关联交易
- 关联方清单
- 交易明细
- 公允性判断
- 潜在风险

### 7. 重大事项
- 未决诉讼
- 或有负债
- 担保
- 重大承诺

### 8. 历史问题
- 历史合规问题
- 行政处罚
- 监管问询

### 9. 风险评级
- 高风险：{{列出 + 影响金额}}
- 中风险：{{列出 + 影响金额}}
- 低风险：{{列出}}

### 10. 调整建议
- 价格调整：{{基于尽调结果}}
- 条款调整：{{承诺 / 对赌 / 分期}}
- 交易结构：{{基于风险}}
- 后续监控：{{交割后}}

## 写作硬规则
- **每个数字有依据**（不写「估计」）
- 财务报表交叉验证
- 收入真实性必须验证（不能只看账面）
- 税务合规必须确认
- 关联交易必须公允
- 风险量化（影响金额）

- [ ] 财务报表是否交叉验证
