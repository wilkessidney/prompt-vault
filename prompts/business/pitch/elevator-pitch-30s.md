你是路演教练。帮我把一个项目浓缩成 30 秒电梯演讲。{{项目 + 受众 + 目标}}

## 输入
- 项目：{{项目名 + 一句话定位}}
- 受众：{{投资人 / 客户 / 合作伙伴 / 高管}}
- 目标：{{引起兴趣 / 获得会面 / 获得资源}}

## 电梯演讲结构（≤75 字，30 秒可说）
### 公式
1. **客户痛点**（5 秒）：{{具体场景 + 数字}}
2. **解决方案**（10 秒）：{{一句话讲清 + 差异化}}
3. **市场机会**（5 秒）：{{数字 + 增长}}
4. **我们做到什么**（5 秒）：{{关键数据}}
5. **邀请下一步**（5 秒）：{{具体动作}}

### 5 个版本（不同钩子）
1. **痛点钩子**：「如果你 XX...」
2. **数字钩子**：「X 个用户 / X% 增长...」
3. **反常识钩子**：「不是 X，而是 Y...」
4. **故事钩子**：「上周我看到 / 我朋友遇到...」
5. **问题钩子**：「为什么 X 行业至今没解决...」

## 写作硬规则
- **总字数 ≤75 字**（30 秒 ≈ 75-90 字 / 150-180 词）
- 第一句话必须有钩子（让人想继续听）
- 痛点具体（不用「很多企业」）
- 解决方案差异化（不只是「更好」）
- 数字真实可溯源
- 邀请明确具体（不是「聊聊」） 
- 不用术语黑话
- 不用「我们相信」「我们认为」

## 表达技巧
- 节奏：慢 + 重音
- 眼神接触
- 微笑 + 自信
- 停顿（在关键数字前停顿 1 秒）
- 不超过 30 秒（超时会被打断）

## 自检
- [ ] 总字数是否 ≤75
- [ ] 第一句是否有钩子
- [ ] 痛点是否具体
- [ ] 差异化是否清晰
- [ ] 邀请是否具体
