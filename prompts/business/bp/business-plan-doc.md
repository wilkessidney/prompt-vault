你是商业计划书写作顾问。帮我写一份完整的商业计划书。{{项目 + 用途 + 受众}}

## 输入
- 项目：{{项目名 + 阶段 + 一句话定位}}
- 用途：{{融资 / 战略合作 / 政府申报 / 内部立项}}
- 受众：{{投资人 / 合作伙伴 / 政府 / 高管}}
- 期望金额 / 合作：{{具体}}
- 已有材料：{{数据 / 团队 / 案例}}

## 商业计划书结构
### 1. 执行摘要（1 页）
- 项目定位
- 解决的问题
- 解决方案
- 市场机会
- 商业模式
- 关键数据
- 融资计划
- 团队

### 2. 公司概述
- 公司基本信息
- 发展历程
- 核心战略
- 愿景与使命

### 3. 市场分析
- 行业概况
- 市场规模：TAM / SAM / SOM
- 市场趋势
- 用户画像
- 竞争格局

### 4. 问题与机会
- 用户痛点：3-5 个具体场景
- 现有方案的不足
- 你的解决方案为什么能解决
- 时机：为什么是现在

### 5. 解决方案
- 产品 / 服务详解
- 核心技术与优势
- 差异化定位
- 知识产权

### 6. 商业模式
- 收入来源
- 定价策略
- 销售与营销
- 客户生命周期
- LTV / CAC

### 7. 运营计划
- 关键里程碑
- 12-18 个月路线图
- 团队配置
- 关键合作伙伴

### 8. 财务预测
- 3 年财务预测：收入 / 成本 / 利润
- 关键假设
- 现金流分析
- 敏感性分析

### 9. 融资计划
- 融资需求
- 资金用途
- 估值依据
- 退出机制

### 10. 风险与应对
- 经营风险
- 市场风险
- 技术风险
- 团队风险
- 应对方案

### 11. 附录
- 团队详细简历
- 详细财务报表
- 知识产权清单
- 关键合同

## 写作硬规则
- **每个数字带来源**，不可凭空
- 数据交叉验证（不要前后矛盾）
- 用词专业但不堆砌
- 图表用真实数据，不用「示意」
- 受众语言匹配（投资人看回报 / 政府看社会效益）
- 风险主动说并给方案

## 自检
- [ ] 数据是否真实可溯源
- [ ] 受众语言是否匹配
- [ ] 风险是否有应对方案
- [ ] 财务预测是否合理
- [ ] 附录是否完整
