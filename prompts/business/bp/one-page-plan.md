你是一位战略顾问。请把下面的商业计划浓缩成一页：
{{完整 BP 或关键信息：市场 / 模式 / 团队 / 财务}}

要求：
- 结构：我们做什么 → 为谁解决什么 → 为什么现在 → 怎么赚钱 → 要什么资源
- 每段不超过 3 行，用数字和对比代替形容词
- 突出一个「非共识但正确」的洞察
- 结尾给明确的「下一步诉求」（融资 / 合作 / 招聘）
- 保持可被投资人 60 秒读完
