你是科普作家。帮我为一个复杂概念构造精准类比。{{概念 + 受众 + 场景}}

## 输入
- 概念：{{要讲的概念}}
- 受众：{{完全不懂 / 有基础 / 进阶}}
- 使用场景：{{文章 / 演讲 / 教学 / 文档}}
- 必须保留的要素：{{概念的哪些部分不能丢失}}
- 避免的类比：{{已被滥用的类比}}

## 类比构造结构
### 1. 概念拆解
- 把概念拆成 3-5 个核心要素
- 每个要素的物理意义 / 数学含义
- 要素之间的关系
- 哪些是「核心」，哪些是「细节」

### 2. 类比目标匹配
- 受众熟悉的领域：{{受众的生活 / 工作 / 兴趣}}
- 受众熟悉的尺度：{{具体 / 抽象 / 微观 / 宏观}}
- 受众的认知层级：{{小学 / 中学 / 大学}}

### 3. 候选类比（3-5 个）
每个候选：
- **映射**：{{概念的 X 对应类比的 Y}}
- **保留度**：{{哪些要素被保留了}}
- **损失度**：⚠️哪些要素被牺牲了
- **直觉性**：{{多快能秒懂}}
- **教学价值**：{{是否促进深层理解}}

### 4. 类比选择
- 选哪个类比作为主类比
- 选哪个作为补充类比
- 类比组合使用

### 5. 类比扩展
- 主类比的边界：{{类比失效的地方}}
- 反例：{{哪些情况下类比不成立}}
- 进阶方向：{{从类比到精确表述的过渡}}

### 6. 类比表达
- 语言：{{简洁 + 口语化}}
- 视觉：{{是否配图}}
- 互动：{{是否可以演示}}
- 节奏：{{先类比再精确}}

### 7. 类比陷阱
- 避免「是 X 就是 X」的同义反复
- 避免过度类比（一个概念不能强行全部类比）
- 避免已滥用的类比（如「时间是金钱」）
- 避免文化敏感类比
- 标注类比的局限性

## 写作硬规则
- 类比必须基于受众熟悉的领域
- 必须保留概念的核心要素
- 类比的局限性必须明确
- 不能用同义反复
- 一个概念可以多个类比互相补充

- [ ] 受众熟悉度是否匹配

- [ ] 局限性是否标注
- [ ] 是否避免滥用类比
- [ ] 是否配合精确表述
