## 输入
- 对象：{{要对比的对象 2-5 个}}
- 维度：{{基于什么对比}}
- 决策：{{选哪个 / 各自适用 / 趋势}}
- 受众：{{自己 / 团队 / 客户}}

## 对比脑图结构
### 1. 对比对象
- 对象 A：{{核心描述}}
- 对象 B：{{同上}}
- 对象 C：{{如有}}

### 2. 对比维度
基于决策需要选维度：

#### 基础维度
- 定义：{{是什么}}
- 来源：{{来自哪}}
- 历史：{{怎么发展}}

#### 能力维度
- 功能：{{能做什么}}
- 性能：{{做得怎样}}
- 限制：{{不能做什么}}

#### 体验维度
- 易用：{{容易上手吗}}
- 可靠：{{稳定吗}}
- 美观：{{好看吗}}

#### 商业维度
- 价格：{{多少钱}}
- 成本：{{总拥有成本}}
- 风险：{{实施风险}}

#### 生态维度
- 社区：{{活跃吗}}
- 资源：{{文档 / 教程}}
- 兼容：{{与其他系统}}

### 3. 维度权重
- 每个维度的权重：{{基于决策}}
- 总权重：{{必须加和到 100%}}

### 4. 对比矩阵
| 维度（权重） | A | B | C |
|-------------|---|---|---|
| 定义 | {{A 定义}} | {{B 定义}} | {{C 定义}} |
| 功能 | {{A 功能}} | {{B 功能}} | {{C 功能}} |
| 性能 | {{A 性能}} | {{B 性能}} | {{C 性能}} |
| 易用 | {{A 易用}} | {{B 易用}} | {{C 易用}} |
| 价格 | {{A 价格}} | {{B 价格}} | {{C 价格}} |
| 风险 | {{A 风险}} | {{B 风险}} | {{C 风险}} |
| **加权总分** | **X** | **X** | **X** |

### 5. 评分方法
#### 客观数据
- 价格、性能、市场份额
- 真实可量化

#### 主观评估
- 易用、体验、社区
- 多人评估取平均

#### 综合评分
- 加权平均
- 或分维度判定

### 6. 关键差异
- 每个对象的核心优势
- 每个对象的核心劣势
- 不可妥协的差异
- 可妥协的差异

### 7. 适用场景
- 对象 A 适合：{{场景 1 + 2}}
- 对象 B 适合：{{场景 3 + 4}}
- 对象 C 适合：{{场景 5 + 6}}

### 8. 决策建议
#### 明确推荐
- 基于权重 + 评分
- 适合场景
- 不适合场景

#### 条件推荐
- 如果你 X：选 A
- 如果你 Y：选 B
- 如果你 Z：选 C

#### 备选方案
- 如果都满足，X 是稳妥选择
- 创新方向：考虑 Y
- 长期考虑：关注 Z

### 9. 决策风险
- 选 A 的风险：{{具体}}
- 选 B 的风险：{{同上}}
- 选 C 的风险：{{同上}}
- 缓解方案

### 10. 持续监控
- 对象变化趋势
- 评分更新
- 决策复审

## 写作硬规则
- 维度必须基于决策
- 权重必须明确
- 数据真实可溯源
- 评分方法清晰
- 决策建议可执行

## 自检
- [ ] 维度是否基于决策
- [ ] 权重是否明确
- [ ] 数据是否真实
- [ ] 评分是否清晰
- [ ] 建议是否可执行
