## 输入
- 主题：{{具体学科 + 子主题}}
- 难度：{{基础 / 中等 / 进阶 / 专家}}
- 考点：{{核心概念 / 细节 / 应用 / 综合}}
- 数量：{{X 道题}}
- 用途：{{自测 / 考试 / 复习}}

## 选择题结构
### 1. 题型
#### 知识型
- 测试记忆
- 「以下哪个是...」
- 「下列哪个正确」

#### 理解型
- 测试理解
- 「以下哪个最能解释」
- 「下列哪个含义」

#### 应用型
- 测试应用
- 「以下哪种情况下」
- 「应该如何处理」

#### 分析型
- 测试分析
- 「基于以上信息」
- 「最能支持论点的」

#### 评价型
- 测试评价
- 「以下哪个评价最准确」
- 「最有价值的」

### 2. 难度分布
- 基础（20%）：直接记忆
- 中等（50%）：理解 + 简单应用
- 进阶（20%）：综合应用
- 专家（10%）：批判分析

### 3. 题目结构
每题包含：

#### 题干
- 清晰的问题陈述
- 必要的背景信息
- 避免歧义

#### 选项
- 4 个选项（最佳）
- 干扰项设计合理
- 长度相近

#### 答案
- 正确答案：{{具体}}
- 解析：{{为什么对 + 为什么错}}

#### 考点标注
- 主题：{{具体子主题}}
- 类型：{{知识 / 理解 / 应用 / 分析}}
- 难度：{{具体}}

### 4. 干扰项设计
#### 常见错误
- 概念混淆
- 范围错误
- 条件不符
- 反例陷阱

#### 干扰强度
- 强干扰：{{容易选错的}}
- 中干扰：{{基于常见误解}}
- 弱干扰：{{明显错误的}}

### 6. 答案解析
#### 正确答案分析
- 为什么选这个
- 核心考点
- 关键概念

#### 错误答案分析
- 为什么错
- 常见误解
- 避免方法

#### 相关知识
- 关联概念
- 拓展阅读

### 7. 题库组织
#### 按主题
- 主题 → 子主题 → 考点
- 树形结构

#### 按难度
- 基础 → 中等 → 进阶 → 专家
- 循序渐进

#### 按题型
- 知识 → 理解 → 应用 → 分析 → 评价
- 能力分层

### 8. 质量控制
#### 题干质量
- 不歧义
- 不冗长
- 不暗示

#### 选项质量
- 同质性
- 干扰合理
- 不明显错

#### 答案质量
- 唯一正确
- 解析充分
- 考点明确

### 9. 使用场景
#### 自测
- 错题归档
- 反复练习
- 弱点识别

#### 考试
- 组卷规则
- 难度平衡
- 时间合理

#### 复习
- 按主题
- 按难度
- 按题型

### 10. 持续优化
- 错题率统计
- 题目难度评估
- 干扰项调整
- 新题补充

## 写作硬规则
- 题干必须清晰无歧义
- 干扰项必须有合理设计
- 答案必须有解析
- 考点必须标注
- 题库必须可持续更新

- [ ] 题干是否清晰
- [ ] 干扰是否合理
- [ ] 答案是否有解析
- [ ] 考点是否标注
- [ ] 是否可持续更新
