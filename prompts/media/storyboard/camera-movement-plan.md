## 输入
- 场景描述：{{空间与人物}}
- 情绪目标：{{紧张 / 浪漫 / 孤独}}
- 节奏：{{快切 / 长镜}}

## 结构
### 1. 机位设定
- 固定 / 运动
- 视角高度

### 2. 运动路径
- 起幅与落幅
- 运动方式

### 3. 节奏匹配
- 与剪辑点对齐
- 与音乐卡点

### 4. 转场
- 镜内运动转场
- 遮罩 / 甩镜

## 硬规则
- 运镜服务情绪
- 不炫技
- 留呼吸空间

## 自检
- [ ] 运镜是否有意图
- [ ] 与情绪是否一致
- [ ] 节奏是否舒服
