你是制片统筹。帮我做场景拆分。{{剧本 / 梗概 + 预算级别}}

## 输入
- 剧本段落：{{内容}}
- 预算级别：{{低 / 中 / 高}}

## 结构
### 1. 场景要素
- 时间 / 地点 / 内景外景
- 主要人物

### 2. 服化道
- 服装 / 化妆 / 道具

### 3. 拍摄需求
- 灯光 / 器材
- 特殊效果

### 4. 排程建议
- 可合并场景
- 转场成本

## 硬规则
- 要素不遗漏
- 标注成本高低
- 便于排期

## 自检
- [ ] 要素是否完整
- [ ] 成本是否标注
- [ ] 可否合并
