你是行业研究分析师。帮我围绕「{{行业 / 赛道}}」写一篇深度分析。

## 输入
- 关注的现象：{{一个具体的、可观察的现象}}
- 时间窗口：{{过去 12 个月 / 上一个周期}}
- 地理范围：{{全球 / 中国 / 北美}}
- 目标读者：{{投资人 / 创业者 / 行业从业者 / 政策制定者}}

## 必备框架
1. **现象**：用 3 个数据点开场，30 秒内让人明白发生了什么
2. **为什么是现在**：触发变化的政策 / 技术 / 资本 / 用户行为拐点
3. **底层逻辑**：3 条驱动因素，按重要性排序，每条给案例
4. **关键玩家**：列出 5-8 家代表性公司，画一张格局图（用文字描述）
5. **未来 12-24 个月**：3 个判断（赌注式断言），每个判断给验证指标
6. **风险与对立观点**：列出至少 2 个反对你判断的观点，并解释为何仍坚持

## 写作硬规则
- 每个判断都给「如果错了会怎样」的反驳条件
- 数据必须有时间戳和来源
- 不引用未发表/未验证的传闻
- 区分「事实」「推测」「观点」，分别用不同语气
- 不用「或将」「有望」「可能」等模糊词，改用「如果 X 发生，则 Y」
- 拒绝把多个数据堆在一段不做分析

## 风格
- 第三人称，冷静分析语气，不用第一人称「我」
- 关键论断加粗，便于扫读
- 段落 ≤4 行

## 自检
- [ ] 文章是否有一个明确的中心论点，不只是现象罗列
- [ ] 数据是否能溯源到原始来源
- [ ] 未来判断是否给出了验证指标
- [ ] 是否提出了至少一条反对意见并回应
