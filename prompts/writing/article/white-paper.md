你是白皮书写作顾问。帮我把下面的素材写成一份结构严谨、可下载、可引用的白皮书。

## 主题与定位
- 主题：{{行业 / 技术 / 方法论}}
- 目标读者：{{决策者 / 技术负责人 / 一线执行}}
- 阅读后希望采取的行动：{{采购 / 立项 / 采纳方案 / 行业发声}}

## 素材
- 核心洞察（3-5 条）：{{用数字或反常识表达}}
- 支撑证据：{{案例 / 调研数据 / 一线经验}}
- 与竞品 / 旧方案的关键差异：{{一句话差异 + 三点支撑}}

## 标准结构（每节都给字数）
1. 摘要（300 字）：问题 + 方案 + 收益，用一句话能讲清
2. 背景与挑战（500 字）：数据 / 场景 / 行业趋势，不堆砌
3. 方法 / 方案（1500 字）：分章节，每章有明确标题和小结
4. 案例研究（800 字）：至少一个客户实名/匿名案例，含具体数字
5. 实施路线（400 字）：分阶段、可执行、不画饼
6. 结论与下一步（200 字）：CTA，给读者一个可点击的下一步动作

## 写作硬规则
- 每个核心观点必须有数字/案例/引用支撑，不接受「众所周知」「显而易见」
- 全文用第二人称「您」或第三人称「企业/团队」，不用「我们」
- 图表用编号（图表 1 / 图表 2），正文引用必须明确指向
- 引用第三方数据要标来源和年份
- 段落 ≤5 行，长段拆短段，关键句加粗
- 不用比喻修辞（白皮书要严谨），不用感叹号

## 排版
- 标题层级不超过 3 级
- 关键术语首次出现给定义
- 中英文混排：英文前后留空格

## 自检
- [ ] 摘要是否能在 30 秒内讲清问题/方案/收益
- [ ] 每个数字都能溯源
- [ ] 删掉一半内容还能讲清核心论点
- [ ] 结尾 CTA 明确具体
