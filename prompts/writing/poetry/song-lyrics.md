你是歌词创作人。帮我写一首 {{类型：流行 / 民谣 / 摇滚 / 古风 / 抒情}} 歌词。

## 输入
- 风格：{{流行 / 民谣 / 摇滚 / 古风 / 抒情 / 城市民谣}}
- 主题：{{爱情 / 青春 / 思乡 / 励志 / 治愈 / 现实}}
- 情绪弧线：{{起点情绪 → 转折 → 终点情绪，三段明确}}
- 故事原型：{{一个具体的、能压缩进 4 分钟的故事}}
- 韵脚风格：{{AABB / ABAB / AABA，明确指定}}

## 结构（按流行歌曲惯例）
1. **前奏/Intro**（可选 1-2 行）：氛围，不进入主题
2. **主歌 Verse 1**（4-8 行）：讲故事，建立场景
3. **预副歌 Pre-Chorus**（2-4 行）：情绪铺垫，制造张力
4. **副歌 Chorus**（4-8 行）：主题句 + 钩子，最强记忆点
5. **主歌 Verse 2**（4-8 行）：故事推进，加入新信息或视角
6. **预副歌 Pre-Chorus**（重复）
7. **副歌 Chorus**（重复）
8. **桥段 Bridge**（4-8 行）：转折，与前文形成对比
9. **末段副歌**（可升调 / 加和声）
10. **尾声 Outro**（可选 1-4 行）：余味

## 写作硬规则
- **副歌必须有钩子句**：3 个字以内的核心短语重复出现
- 主歌叙事，副歌抒情，避免在副歌里讲故事
- 韵脚自然，不强凑韵（「爱你」「离去」押韵但生硬）
- 押韵方案整体一致，桥段可换韵以制造对比
- 不堆砌「啊」「呀」「哦」之类语气词
- 每句长度 7-10 字为主，便于演唱
- **口语化**，不写「此情可待成追忆」式古文歌词

## 韵脚与节奏
- 重音字放在句末
- 长句不超过 14 字
- 段落内部要有节奏对比（长短交错）

## 自检
- [ ] 副歌是否能在 30 秒内形成记忆
- [ ] 主歌是否在讲故事
- [ ] 韵脚是否自然不生硬
- [ ] 情绪弧线是否清晰（3 段）
- [ ] 整体长度是否适合演唱（≤4 分钟）
