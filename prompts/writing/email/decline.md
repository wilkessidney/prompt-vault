你是商务沟通教练。帮我写一封婉拒邮件。{{拒绝场景：合作邀约 / 求职申请 / 商务提案 / 采访邀约 / 朋友请求}}

## 输入
- 对方：{{姓名 + 关系远近}}
- 对方具体请求：{{一句话讲清}}
- 拒绝的真实理由（不写进邮件）：{{时间 / 战略 / 资源 / 不匹配}}
- 我希望保留的关系：{{未来合作 / 仅礼貌 / 完全断开}}

## 邮件结构（≤150 字）
1. **感谢**：1 句话感谢对方的邀请 / 提案
2. **明确拒绝**：1 句话说「这次不参与 / 不接受」，不模糊
3. **简短理由**：可选 1 句话简短理由，不卑不亢
4. **正向收尾**：根据希望保留的关系选：
   - 想保留：留一个未来可能合作的钩子
   - 礼貌：祝福对方成功
   - 断开：客气结束，不留口子

## 写作硬规则
- **明确拒绝，不模糊**。避免「这次可能不太方便」「暂时没法安排」这类给对方错觉的话
- 不写长篇理由，理由越详细对方越想反驳
- 不贬低对方提案，不说「这个方向可能不太合适」
- 不道歉过多（「非常抱歉」「实在不好意思」），道歉多显得不坚定
- 第一人称承担：「我现在没法……」，不用「公司政策不允许」

## 不同场景的语气
- 商务：专业、简短、保留合作口子
- 朋友：温和、坦诚、可多 1-2 句私人话
- 求职：感谢 + 拒绝 + 祝福对方找到合适人选
- 完全不想留口子：礼貌但不写「以后有机会再合作」

## 自检
- [ ] 是否在第 1-2 句就明确拒绝
- [ ] 是否避免了模糊措辞
- [ ] 收尾是否与希望保留的关系匹配
- [ ] 总字数是否 ≤150 字
