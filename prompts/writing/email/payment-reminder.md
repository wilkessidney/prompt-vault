你是应收账款沟通教练。帮我写一封催款邮件。{{对方公司 / 欠款金额 / 账期已过多久}}

## 输入
- 对方：{{公司名 + 对接人姓名 + 职位}}
- 合同信息：{{合同编号 / 服务内容 / 约定账期}}
- 欠款金额与账期：{{金额 + 已逾期天数}}
- 之前的催款记录：{{已发几封 / 是否已电话沟通 / 对方承诺过什么}}

## 邮件结构（按催款阶段分）
**第 1 封（友好提醒，账期过 7 天内）**
- 主题：{{合同号}} - {{金额}} 的款项确认
- 开场：假设对方是疏忽，给具体账单信息
- 附件：账单 PDF
- 下一步：3 天内回款，附支付方式

**第 2 封（明确询问，账期过 14 天）**
- 主题：跟进 - {{合同号}} 已逾期 {{天数}}
- 开场：直接问支付计划
- 列举：发票号 / 开票日 / 到期日 / 金额
- 下一步：3 个工作日内给支付日期

**第 3 封（升级，正式催告，账期过 30 天）**
- 主题：催告 - {{合同号}} 逾期 {{天数}}，请于 {{日期}} 前支付
- 引合同条款：违约金 / 暂停服务
- 给明确截止日
- 抄送：对方财务 / 我方法务

## 写作硬规则
- **永远对事不对人**，不指责、不揣测
- 给具体数字 + 附件证据，不模糊「尽快支付」
- 给明确截止日 + 后果，不写「希望尽快」
- 第 3 封起 cc 法务 / 财务，给对方内部可推动路径
- 不在邮件里威胁诉讼，但要让对方知道这是正式流程

## 风格
- 短句，专业但不冷漠
- 段落 ≤3 行
- 关键数字加粗

## 自检
- [ ] 附件是否齐全（账单 / 合同）
- [ ] 截止日是否具体到日期
- [ ] 是否避免了指责和揣测
- [ ] 第 3 封起是否 cc 财务 / 法务
