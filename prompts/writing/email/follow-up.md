你是销售沟通教练。帮我写一封客户跟进邮件。{{上次沟通时间 / 形式 / 关键讨论点}}

## 输入
- 上次沟通：{{时间 + 形式 + 我方承诺了什么 / 客户方反馈了什么}}
- 客户状态：{{未回复 / 已读未回 / 已表达兴趣但未推进 / 已婉拒}}
- 我希望的下一步：{{再约会议 / 推进合同 / 解决异议 / 重新激活}}

## 邮件结构
1. **主题**（≤10 字）：直接说明目的，如「跟进：{{上次话题}}」或「上次沟通的 3 个跟进项」
2. **开场**（1 句）：自然唤起上次沟通，不重复寒暄
3. **我方兑现**：上次承诺过的事，做到了 / 进展 / 待办
4. **新增价值**：上次沟通后新增的 1 个信息 / 案例 / 数据
5. **明确下一步**：具体时间 + 具体动作 + 让对方容易选 A/B 二选一

## 写作硬规则
- **不重复上次邮件内容**，只讲新增 + 下一步
- 不写「打扰了」「不好意思又打扰」之类卑微开场
- 不堆砌「希望尽快回复」「期待您的反馈」
- 不发邮件轰炸：未回复前最多 2 封，且间隔 ≥3 个工作日
- 二选一选项必须真实可执行，不要把对方推到「考虑考虑」

## 不同状态专用开场
- 未回复：「上次发的内容可能没说明白，这次换个角度讲……」
- 已读未回：「想确认一下你是否看到了，上次讲到的 X 方案」
- 已表达兴趣：直接给下一步（合同 / 会议 / 试用）
- 已婉拒：3 个月后再触达，给新价值再问一次

## 自检
- [ ] 主题是否 ≤10 字且明确
- [ ] 是否讲了「我方兑现了什么」
- [ ] 二选一选项是否真实可执行
- [ ] 是否避免了卑微开场和催促语气
