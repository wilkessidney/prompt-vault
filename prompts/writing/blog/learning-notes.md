你是学习笔记教练。帮我把「{{书名 / 课程名 / 主题}}」整理成一份能反复回看的学习笔记。

## 输入
- 来源：{{书 / 课 / 论文 / 一系列文章}}
- 我读这本书的目的：{{解决具体问题 / 入门新领域 / 找新思路}}
- 已读过：{{章节 / 章节号 / 整体}}
- 我的背景：{{已有的相关知识}}

## 笔记结构
1. **一句话总结**：这本书 / 课程最核心的一句话是什么
2. **核心论点**：3-5 条，按重要性排序，每条 ≤3 行
3. **关键概念卡**：列出 10-20 个关键术语 / 框架，每个给：定义 + 一句话例子 + 我自己的理解
4. **行动清单**：读完我打算做 / 改变 / 试一下的 5 件事
5. **与我已有认知的连接**：和 {{我已有的某知识}} 的关联
6. **反驳 / 保留意见**：哪些点我不完全同意 / 需要更多证据
7. **推荐阅读 / 下一步**：3-5 条延伸资料

## 笔记硬规则
- **用自己的话写**，不抄原文 / 不抄金句
- 每个概念卡必须有「我自己的理解」，哪怕只有一句话
- 区分「作者说的」「我认为」「我还需要验证的」
- 不引用原文段落超过 3 行（避免变成摘抄）
- 不写「读起来很棒」「非常推荐」之类无信息评价

## 排版
- 概念卡用表格或定义列表
- 关键结论加粗
- 一页一个核心概念卡，便于卡片记忆法复习
