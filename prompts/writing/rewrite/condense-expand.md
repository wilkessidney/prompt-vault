## 输入
- 原文：{{粘贴要改写的文字}}
- 目标长度：{{目标字数 / 目标百分比}}
- 目标读者：{{读者画像}}
- 保留要求：{{必须保留的核心信息、关键术语、不能删的数据}}
- 语气保留度：{{完全一致 / 可微调 / 可重塑}}

## 改写结构
1. **先列核心信息**：从原文提取 5-10 条关键信息点
2. **判断哪些必保留**：标出必保留项与可省略项
3. **结构重排**：按目标长度重新组织段落顺序
4. **逐段改写**：
   - 缩写：合并同义句、删例子 / 数字细节、压缩引语
   - 扩写：补具体场景 / 例子 / 数据细节、加过渡、加层次
5. **语气校准**：对照原文调整语气一致度

## 缩写硬规则
- 删除重复信息（同一观点用不同词重述两次）
- 删除修饰性形容词
- 合并同类案例
- 保留所有数字 + 引用
- 不删核心论据

## 扩写硬规则
- 加具体场景 / 案例 / 数据
- 加层次（从抽象到具体，或反过来）
- 加过渡句，让结构更清晰
- 不重复原观点，只增加新维度
- 不写空话（「这个观点非常重要」）

## 全程硬规则
- 不改变原文核心观点
- 不改变原文事实 / 数字
- 不改变原文的语气基调
- 关键术语 / 命名不翻译

## 自检
- [ ] 核心信息是否完整保留
- [ ] 字数是否达标（±10%）
- [ ] 语气是否与原文一致
- [ ] 是否有意外的信息增删
