## 输入

- 口语化场景：{{朋友聊天 / 演讲口播 / 短视频旁白 / 公众号口语专栏}}
- 目标读者：{{年龄 / 关系 / 地域}}
- 保留要求：{{必须保留的核心信息 / 术语 / 数据}}

## 改写方法
1. **拆长句**：把 >30 字的句子拆成 ≤20 字的短句
2. **换书面词**：「然而」→「但是」，「鉴于」→「因为」，「故」→「所以」
3. **去翻译腔**：「进行 / 实施 / 开展」改为具体动作；删除被动语态
4. **加过渡**：用「就是说」「其实」「简单来说」等口语连接
5. **加节奏**：长短句交替，关键句单列

## 改写硬规则
- **不删除原信息**，只改表达方式
- 不改变事实 / 数字 / 立场
- 不加入原文没有的情绪（「令人遗憾」→「挺可惜的」可，「令人振奋」→原文没情绪不加）
- 不滥用网络流行语（「yyds」「绝绝子」慎用，过时快）
- 不用第一人称除非原文已有
- 关键术语保留，第一次出现给口语解释

## 不同场景的差异化
- 朋友聊天：可加语气词「吧」「呢」「啊」，但不过度
- 演讲口播：节奏感强，关键句重复
- 短视频旁白：前 5 秒必须有钩子
- 公众号口语：段落短，多用「你」
