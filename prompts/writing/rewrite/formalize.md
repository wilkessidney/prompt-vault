你是专业化改写教练。帮我把下面这段 {{口语 / 笔记 / 邮件 / 聊天记录}} 改成正式书面表达。

## 输入
- 原文：{{粘贴原文}}
- 目标场景：{{报告 / 公文 / 合同 / 学术论文 / 商务邮件 / 制度文件}}
- 受众：{{上级 / 客户 / 公众 / 同行专家}}
- 保留要求：{{核心信息 / 数据 / 立场}}

## 改写方法
1. **消除口语词**：「搞定」→「完成」，「弄一下」→「处理」，「差不多」→「基本」
2. **去语气词**：删除「吧」「呢」「啊」「哦」
3. **去第一人称**：用「本部门」「贵公司」「作者」「笔者」等
4. **加结构**：明确「背景 → 现状 → 问题 → 建议」等结构
5. **用书面动词**：「说」→「指出」「表示」「认为」，「做」→「开展」「执行」「实施」
6. **加连接词**：「首先 / 其次 / 此外 / 最后」「综上 / 因此」

## 改写硬规则
- **不改变事实和数据**
- 不夸大原文（「挺好的」→「效果显著」不可以，原文模糊就保留模糊）
- 不堆砌专业术语，原文没说的别加
- 不改变立场 / 态度
- 长句可用，但避免 50 字以上超长句

## 场景差异化
- 报告：数据明确，结论先行
- 公文：套语合规，但避免过度套话
- 合同：法条准确，要素完整
- 学术论文：术语严谨，可引用文献
- 商务邮件：简洁专业，但不冷冰冰
- 制度文件：条目化，可执行

## 自检
- [ ] 是否消除了全部口语词 / 语气词
- [ ] 结构是否清晰
- [ ] 事实和数据是否保留
- [ ] 是否避免了过度套话
