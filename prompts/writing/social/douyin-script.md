你是抖音短视频脚本作者。帮我写一条 {{时长：15 秒 / 30 秒 / 60 秒}} 的脚本。

## 输入
- 时长：{{15 秒 / 30 秒 / 60 秒}}
- 类型：{{口播 / 剧情 / 测评 / 教学 / vlog / 知识}}
- 钩子素材：{{反常识 / 痛点 / 视觉奇观 / 名人 / 数字}}
- 目标：{{涨粉 / 转化 / 品牌曝光 / 带货}}
- 关键信息：{{必须传达的 1 个核心信息}}

## 脚本结构（按秒拆解）
### 0-3 秒：钩子（决定 80% 完播率）
- 视觉钩子：一个动作 / 表情 / 场景
- 听觉钩子：一句话抓人
- 文字钩子：字幕大字点出反差 / 反常识

### 3-10 秒：背景
- 30 字内讲清背景
- 用「你 / 我们」代入
- 不超过 2 句话

### 10-25 秒：核心内容
- 3 个要点，每个 ≤5 秒
- 数字 / 案例 / 演示
- 不要超过 3 个要点（信息过载会划走）

### 25-30 秒：收尾 + CTA
- 重申核心信息
- 明确 CTA：关注 / 评论 / 点击购物车 / 收藏

## 写作硬规则
- **总字数：15 秒 ≤80 字，30 秒 ≤180 字，60 秒 ≤350 字**
- 不写「大家好我是 XX」之类开场
- 不铺垫、不寒暄、不自我介绍
- 每句话必须推进信息或情绪
- 关键数字 / 反差用大字字幕
- 不出现微信 / 二维码（违规）
- 不出现品牌名 unless 必要

## 不同类型差异
- 口播：节奏快，多用短句
- 剧情：3 秒反转 / 冲突开场
- 测评：直接给结论，再讲理由
- 教学：步骤 1/2/3 标号
- vlog：情绪先行，故事后置

## 自检
- [ ] 前 3 秒是否有钩子
- [ ] 总字数是否达标
- [ ] 是否每个字都在推进信息
- [ ] CTA 是否明确具体
