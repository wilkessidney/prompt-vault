你是广告创意总监。帮我为一个产品 / 服务写出 5 个广告标题。

## 产品输入
- 产品 / 服务：{{名字 + 一句话定位}}
- 目标受众：{{身份 + 痛点 + 梦想}}
- 核心差异化：{{与竞品的本质差异，不只是功能差异}}
- 品牌调性：{{专业 / 温暖 / 叛逆 / 高端 / 平价 / 科技}}
- 使用场景：{{品牌口号 / 信息流广告 / 海报 / TVC / 户外}}

## 5 个标题方案（覆盖不同策略）
1. **利益承诺**：「{{具体收益}}」，≤8 字
2. **反常识**：「颠覆 / 推翻 / 不必 {{常见做法}}」
3. **身份认同**：「为 {{特定人群}} 而生」
4. **场景代入**：「{{场景}} 时，你只需要 {{产品}}」
5. **品牌态度**：「{{价值观表达}}」

## 写作硬规则
- **每个标题必须能脱离产品单独成立**（测试方法：拿掉产品名，标题依然成立说明有主张）
- ≤12 字（Slogan）/ ≤20 字（信息流广告）
- 不写「专业」「优质」「值得信赖」之类无差别形容词
- 不写「让 XX 变得简单」之类口号（无差异化）
- 不堆砌形容词：「最好」「最强」「第一」禁用
- 至少 2 个标题含具体数字 / 时间 / 场景

## 类型差异化
- 品牌 Slogan：长期使用，要价值观共鸣，≤8 字
- 信息流广告：直接给收益 + 行动引导，≤20 字
- 海报标题：可文艺 / 留白，但要钩子
- TVC：要有情绪，能让人停下

- [ ] 是否避免了无差别形容词
