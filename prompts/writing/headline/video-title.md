你是视频标题优化师。帮我为一条视频写出 5 个标题方案。{{平台：B站 / 抖音 / YouTube / 视频号}}

## 视频输入
- 平台：{{B站 / 抖音 / YouTube / 视频号}}
- 内容类型：{{教程 / 测评 / vlog / 观点 / 剧情 / 知识}}
- 时长：{{短视频 < 1 分钟 / 中视频 1-10 分钟 / 长视频 > 10 分钟}}
- 核心信息：{{一句话讲清这条视频讲什么}}
- 已有钩子素材：{{数字 / 反转 / 名人 / 痛点 / 视觉奇观}}

## 5 个标题方案（按平台差异化）
1. **好奇心钩子**：「{{不剧透结果}}，但暗示关键信息」
2. **数字 + 价值钩子**：「{{数字}} + 具体收益」，如「5 个让 XX 翻倍的技巧」
3. **反差钩子**：「{{身份反差}} + 主题」，如「清华教授教我洗碗」
4. **时效钩子**：「{{最新 / 刚刚 / 突发}} + 事件」
5. **痛点 + 解药钩子**：「{{痛点}} 的 {{解药}}」

## 平台硬规则
- **B站**：≤30 字，可含「【】」「#tag」，鼓励互动词（「你 XX 吗」）
- **抖音**：≤22 字，前 8 字必须有关键信息，不完整句也行
- **YouTube**：≤60 字符，英文可全大写关键词，含 SEO 关键词
- **视频号**：≤15 字，简洁、含情感

## 全平台禁忌
- 「震惊」「必看」「转疯了」等夸张词
- 「不转不是中国人」等道德绑架
- 「最」「第一」等绝对化用语（平台限流）
- 标题党：标题与内容必须真实对应
- 完全剧透：留 1 个未解信息

## 自检
- [ ] 5 个方案是否覆盖 5 种钩子
- [ ] 字数 / 字符数是否符合目标平台
- [ ] 是否避免了平台限流词
- [ ] 标题是否能与封面图形成「双重钩子」
