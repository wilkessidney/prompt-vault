## 世界观输入
- 类型：{{奇幻 / 科幻 / 架空历史 / 现代都市 + 超自然 / 反乌托邦}}
- 核心规则 / 矛盾：{{一句话讲清这个世界的「奇异之处」}}
- 灵感来源：{{参考的作品 / 现实原型 / 历史背景}}
- 我想要的氛围：{{冷峻 / 温暖 / 黑色 / 史诗}}

## 世界观结构
1. **物理规则**：时间 / 空间 / 物质 / 能量怎么运作
2. **核心矛盾 / 异常**：这个世界与现实世界的关键差异
3. **历史**：这个世界的过去，关键事件和时代划分
4. **社会结构**：权力分布 / 阶层 / 经济 / 主流意识形态
5. **日常生活**：普通人一天怎么过（食物 / 衣着 / 信仰 / 娱乐）
6. **禁忌与边界**：哪些事不能做 / 不能想 / 不能问
7. **语言与命名**：地名 / 人名 / 关键术语的命名逻辑
8. **未解之谜**：3-5 个留给故事推进的核心谜题

## 写作硬规则
- **每个设定都要可被故事利用**，不接受「虽然存在但故事用不到」的装饰设定
- 物理规则必须自洽，写明边界条件
- 历史事件要有「不同势力的视角」，不留单一官方叙事
- 日常生活要落到具体细节，不要泛泛「他们很勤劳」
- 命名要有内在逻辑（语言家族 / 文化源流），不要随机
- 未解之谜必须在故事中有伏笔对应

## 风格
- 设定文档本身要像世界内部百科的一个条目
- 段落 ≤5 行
- 关键设定加粗

## 自检
- [ ] 每个设定是否能对应到一个具体故事场景
- [ ] 物理规则是否自洽且边界清晰
- [ ] 是否给出了至少 3 个未解之谜供故事推进
- [ ] 命名是否有内在逻辑可循
