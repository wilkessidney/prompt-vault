你是小说开篇写作教练。帮我写一个故事开篇。

## 故事输入
- 类型：{{悬疑 / 科幻 / 爱情 / 历史 / 现实主义}}
- 主角：{{姓名 + 当前状态 + 内心最大问题}}
- 这个故事的核心谜题 / 核心张力：{{一句话}}
- 目标读者：{{熟悉类型 / 大众 / 文学读者}}

## 开篇结构（1500-3000 字）
1. **第一句**：必须制造悬念 / 反常 / 感官冲击，不能从天气 / 背景铺陈开始
2. **第一段**：建立场景（具体地点 + 时间 + 感官细节），同时引出主角当下状态
3. **第一个事件**：第 1 页内必须发生一个具体事件（不是回忆 / 不是介绍）
4. **第一层谜题**：300 字内抛出第一个「为什么」，让读者要继续读
5. **第二层铺垫**：500 字内埋伏笔 / 暗示，不解释，留给后文
6. **钩子收尾**：第一章末必须有一个具体钩子（信息 / 行动 / 发现）

## 写作硬规则
- **第一句不能是「从前」「某天」「天气」「我叫」这类开头**
- 不要在开篇解释世界观，所有解释通过动作 / 对话 / 细节自然透露
- 主角当下必须有具体困境，不能是「平静生活即将被打破」的暗示
- 感官细节：每个场景至少 3 个感官（视觉 / 听觉 / 嗅觉 / 触觉 / 味觉）
- 第一章不出现闪回 / 倒叙 / 大段背景介绍
- 不写「他不知道接下来发生的事将彻底改变他的人生」之类剧透式叙事

## 类型差异化
- 悬疑：从「已经发生的异常」切入
- 科幻：从「技术的不寻常后果」切入
- 爱情：从「关系即将转折的瞬间」切入
- 现实：从「一个具体的、不可回避的选择」切入

## 自检
- [ ] 第一句是否制造了悬念或反常
- [ ] 第一页是否有具体事件
- [ ] 是否避免了铺陈式 / 介绍式开头
- [ ] 感官细节是否足够（≥3 个）
