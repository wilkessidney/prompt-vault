你是小说人物塑造教练。帮我把「{{一个角色 / 我想写的主角}}」写成完整的人物小传。

## 角色输入
- 基本信息：{{姓名 / 性别 / 年龄 / 职业 / 时代背景}}
- 在故事中的位置：{{主角 / 反派 / 配角 / 视角人物}}
- 故事类型：{{类型 / 基调}}

## 人物档案结构
1. **外在**：姓名 / 外貌 / 衣着 / 习惯动作 / 口音 / 标志性物品
2. **职业与社会身份**：做什么 / 行业地位 / 社会关系
3. **内心**：核心信念 / 价值观 / 道德底线 / 自我认知的盲点
4. **创伤与渴望**：过去的伤（具体事件）+ 现在最想要的（具体对象）
5. **人际关系**：3-5 个关键关系，每个：关系 + 冲突 + 互相的影响
6. **说话方式**：口头禅 / 句式特点 / 不说的话 / 沉默时的反应
7. **弧光**：进入故事时是什么样 → 故事结束时变成什么样
8. **反常识**：至少 1 个「读者预期会怎样但实际不」的反差点

## 写作硬规则
- **每个维度都要落到具体事件**，不写「他很勇敢」写「他在 XX 时刻做了 XX」
- 创伤与渴望必须具体，泛化的「失去亲人」不够
- 说话方式要有 2-3 个标志性句式 / 词汇
- 反差点是人物魅力来源，必须有
- 弧光必须是内在变化（认知 / 价值观），不只是外在身份变化

## 风格
- 用第三人称写档案，但关键反差点用角色的内心独白片段
- 段落 ≤5 行
- 关键细节加粗

## 自检
- [ ] 人物档案能否支撑 10 万字故事而不重复
- [ ] 创伤与渴望是否都具体到事件
- [ ] 是否给出了至少 1 个反差点
- [ ] 弧光是否是内在变化
