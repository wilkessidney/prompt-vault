- 业务：{{网站类型 + 目标}}
- 核心主题：{{3-5 个 pillar topics}}
- 受众：{{画像 + 搜索意图}}
- 现有内容：{{评估 + 差距}}

## 主题集群结构
### 1. 集群设计
#### Pillar Page（支柱页）
- 主题：{{广泛 + 高搜索量}}
- 字数：{{3000-5000 字}}
- 结构：{{全面覆盖主题}}
- 目的：{{权威性 + 内部链接中心}}

#### Cluster Pages（集群页）
- 主题：{{具体长尾词}}
- 字数：{{1500-2500 字}}
- 数量：{{每个 Pillar 下 10-20 个}}
- 目的：{{覆盖长尾 + 链接回 Pillar}}

### 2. 主题选择
#### Pillar 主题标准
- 高搜索量：{{基于关键词研究}}
- 核心业务：{{与产品 / 服务强相关}}
- 广度：{{可延伸出多个子主题}}

#### Cluster 主题标准
- 长尾关键词：{{具体问题}}
- 子主题：{{Pillar 的某个方面}}
- 用户意图清晰：{{能独立满足搜索需求}}

### 3. 内容架构
#### 示例：电商网站「咖啡机」主题
- Pillar：「咖啡机选购指南」
  - Cluster 1：{{「家用咖啡机推荐」}}
  - Cluster 2：{{「半自动 vs 全自动」}}
  - Cluster 3：{{「胶囊咖啡机 vs 滴滤」}}
  - Cluster 4：{{「办公室咖啡机」}}
  - ...

#### 内容关联
- 每个 Cluster 链接回 Pillar
- Pillar 链接到所有 Cluster
- Cluster 之间互链（相关内容）
- 锚文本自然

### 4. 内容生产节奏
- 月发布：{{Cluster 页 X 篇}}
- 季度更新：{{Pillar 页更新}}
- 年度审查：{{集群结构优化}}

### 5. 内部链接策略
- 链接结构：{{Pillar 是中心节点}}
- 锚文本：{{自然含关键词}}
- 链接数：{{每页 5-10 个内链}}
- 死链检查：{{定期清理}}

### 6. 内容差异化
- 与竞品差异：{{独有视角 / 数据 / 案例}}
- 内容质量：{{E-E-A-T 标准}}
- 更新频率：{{保持内容新鲜}}
- 用户价值：{{真正解决问题}}

### 7. 数据监控
- 集群流量：{{整体 vs 单页面}}
- 关键词排名：{{Pillar + Cluster 词}}
- 内链效果：{{链接贡献}}
- 用户行为：{{停留 + 转化}}

### 8. 集群扩展
- 新 Pillar：{{基于业务增长}}
- 新 Cluster：{{基于关键词机会}}
- 跨集群：{{链接 + 整合}}
- 内容退休：{{过时 / 失效内容}}

### 9. 与其他 SEO 策略协同
- 技术 SEO：{{网站结构支持}}
- 外链建设：{{集群整体权威性}}
- 用户体验：{{内容访问路径}}
- 转化：{{从内容到转化的路径}}

## 写作硬规则
- Pillar 必须有真正的搜索量
- Cluster 必须有清晰搜索意图
- 内部链接结构清晰
- 内容生产节奏可持续
- 集群基于业务目标
