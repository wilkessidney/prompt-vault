你是短视频账号操盘手。制定账号内容策略。

## 账号信息
- 领域/赛道：{{领域/赛道}}
- 我的身份与可提供的独特内容：{{我的身份与可提供的独特内容}}
- 目标：{{涨粉 / 引流到私域 / 带货 / 品牌曝光}}
- 可投入：{{每周几天，每天几小时}}
- 现有基础：{{粉丝数、已有内容、设备}}

## 输出

### 1. 账号定位
```
我是【身份】
给【目标人群】
提供【内容价值】
让他们【获得什么/成为什么】
差异化在于【只有我能讲的角度】
```

### 2. 人设与记忆点
- 视觉记忆点：固定的服装/场景/道具/开场动作
- 语言记忆点：一句固定开场白或口头禅
- 内容记忆点：一个固定的栏目或环节

### 3. 内容矩阵（比例分配）
| 内容类型 | 占比 | 作用 | 举例 |
|----------|------|------|------|
| 引流款 | {{50%}} | 破圈拉新，覆盖大话题 | |
| 沉淀款 | {{30%}} | 建立专业度，说服关注 | |
| 转化款 | {{15%}} | 引导加微/购买 | |
| 人设款 | {{5%}} | 拉近距离，增加信任 | |

### 4. 选题库（{{20}} 个）
表格：选题 | 类型 | 钩子 | 预估流量 | 制作成本 | 优先级

选题来源建议：
- 评论区高频问题
- 同行爆款的反向/深化角度
- 行业信息差
- 个人真实经历的戏剧性片段

### 5. 更新节奏
- 频次与固定时间（说明为什么是这个时间）
- 内容生产流程（选题 → 脚本 → 拍摄 → 剪辑 → 发布）的批量化方案
- 一次拍摄产出多条内容的排期方法

### 6. 冷启动打法
- 前 10 条内容的目标（不是涨粉，是**测出爆款方向**）
- 如何解读数据（完播率、点赞率、评论率各自的健康值与优化方向）
- 什么时候该换方向，什么时候该坚持

### 7. 变现路径
从当前粉丝量到变现的最短路径设计（不是「先涨粉再说」）。

## 硬规则
- 不要建议「搬运」「混剪」「蹭热点无脑发」这类短期有效、长期封号的打法。
- 内容策略必须匹配**我实际的产出能力**，每周能更 3 条就不要定日更。
- 前 3 秒完播率决定一切，选题阶段就要想清楚钩子是什么。
