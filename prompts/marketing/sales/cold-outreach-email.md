## 输入
- 产品 / 服务：{{产品名 + 核心价值}}
- 目标客户：{{职位 + 行业 + 规模}}
- 价值主张：{{1 句话讲清能为客户带来什么}}
- 已有素材：{{客户案例 / 数据 / 资质}}
- 触达场景：{{为什么是现在触达}}

## 冷邮件结构
### 1. 主题行（决定打开率）
候选 5 个主题，每个标注类型：
- 个性化：{{提到对方公司 / 角色}}
- 价值：{{具体收益}}
- 好奇：{{引发好奇}}
- 数据：{{数字 / 结果}}
- 反常识：{{反直觉视角}}

要求：≤50 字，不夸张，不制造紧迫。

### 2. 第一段（个性化钩子）
- 用 1 句证明你了解对方
- 来源：{{研究对方公司 / 公开信息 / 共同联系人}}
- 不写「我们公司提供」式开场

### 3. 第二段（价值主张）
- 一句话价值：{{对方视角的具体收益}}
- 量化：{{时间 / 成本 / 增长}}
- 不写功能，写收益

### 4. 第三段（证据）
- 案例：{{1-2 个相似客户的数字}}
- 资质：{{媒体报道 / 行业奖项}}
- 数据：{{转化率 / 增长率}}

### 5. 第四段（低门槛 CTA）
- 具体：{{「15 分钟通话」而非「聊聊」}}
- 时间：{{给出具体选项}}
- 备选：{{「不感兴趣也请告诉我」}}

### 6. 邮件长度
- 全文：≤120 字
- 段落：≤2 行
- 没有废话

## 跟进序列（5-7 封）
### 第 1 封（发送当天）
- 完整邮件（如上）

### 第 2 封（T+3 天）
- 主题：{{不同角度}}
- 内容：{{1 句价值 + 1 个案例 + CTA}}
- 不重复第 1 封内容

### 第 3 封（T+7 天）
- 主题：{{新价值点}}
- 内容：{{行业洞察 / 数据 / 报告}}
- 软性 CTA

### 第 4 封（T+14 天）
- 主题：{{「最后一次」}}
- 内容：{{重新包装价值}}
- 紧迫但不强推

### 第 5 封（T+21 天）
- 主题：{{纯价值，无 CTA}}
- 内容：{{提供资源 / 报告 / 模板}}
- 「拿走用就行」

### 第 6 封（T+30 天）
- 主题：{{最终}}
- 内容：{{优雅告别}}
- 「欢迎未来合作」

## 写作硬规则
- 每封邮件价值优先，不重复
- 个性化基于真实研究
- CTA 越具体越好
- 不强推 / 不套路
- 跟进间隔合理（不要连续轰炸）

## 自检
- [ ] 主题是否吸引打开
- [ ] 价值是否清晰
- [ ] 案例是否真实
- [ ] CTA 是否具体
- [ ] 跟进序列是否提供持续价值
