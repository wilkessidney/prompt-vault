## 输出

### 1. 开场（前 30 秒决定成败）
给出 3 个开场版本：
- **价值钩子型**：一句话说出可能带来的具体收益
- **第三方背书型**：提到同行业的客户名
- **问题切入型**：直接抛出一个客户大概率存在的问题

每个版本：原话 + 为什么有效 + 适用客户类型

**禁止的开场**：
- 「您好，打扰一下，我是 XX 公司的」（会被立刻挂断）
- 「请问你们现在有 XX 需求吗」（客户会说没有）

### 2. 探需提问（SPIN 框架）
| 类型 | 目的 | 问题示例 |
|------|------|----------|
| **S 现状问题** | 了解背景 | |
| **P 难点问题** | 找到痛点 | |
| **I 影响问题** | 放大代价（量化） | |
| **N 需求-效益问题** | 让客户自己说出价值 | |

要求：I 类问题最关键，要帮客户把痛点换算成**金额或时间成本**。

### 3. 价值陈述（FAB → 利益）
```
特点 Feature：产品有什么
优势 Advantage：比别家好在哪
利益 Benefit：对客户意味着什么（要量化）
证据 Evidence：案例、数据、演示
```
给出 3 条完整的 FABE 陈述。

### 4. 演示/提案结构
不是讲产品功能，而是讲「你的问题 → 我们的解法 → 具体场景 → 预期效果」。
给出逐页的讲述要点。

### 5. 成交与推进
- **试探成交**：3 个低压力的试探话术
- **假设成交**：`如果价格没问题，我们下周可以安排试用`
- **稀缺/紧迫**：必须使用**真实的**理由

### 6. 跟进节奏
表格：第 N 次接触 | 间隔 | 内容 | 目的 | 话术
覆盖从首次接触到成交的完整链路（含「客户不回复」时的处理）。

## 硬规则
- 不要背话术，话术的作用是**让你知道每个阶段的目标是什么**。
- 禁止夸大功能与虚假案例。
- 客户说「考虑一下」时，不要追问「您在考虑什么」，而要问「您还需要了解哪方面的信息才能做决定」。
