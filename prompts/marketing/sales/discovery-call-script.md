你是 B2B 销售教练。帮我设计一次需求探询通话的脚本。{{产品 + 客户 + 阶段}}

## 输入
- 客户：{{公司 + 角色 + 阶段}}
- 产品：{{产品名 + 价值}}
- 通话目标：{{了解需求 + 建立关系 + 推进下一步}}
- 通话时长：{{30 / 45 / 60 分钟}}
- 已了解信息：{{客户背景 + 痛点}}

## 通话结构
### 1. 破冰（3-5 分钟）
- 关系建立：{{暖场 + 共情}}
- 议程告知：{{「今天 30 分钟我会聊 3 件事」}}
- 节奏预期：{{告知通话时长 + 节奏}}

### 2. 客户背景（5-10 分钟）
- 公司现状：{{业务 + 规模 + 阶段}}
- 决策角色：{{角色 + 决策权}}
- 当前痛点：{{主动问开放性问题}}
- 已尝试方案：{{用过什么 / 效果如何}}
- 未来规划：{{12 个月目标}}

### 3. 痛点深挖（10-15 分钟）
#### 提问框架
- 当前状态：{{「现在怎么做的」}}
- 痛点影响：{{「不解决会怎样」}}
- 已有尝试：{{「试过什么 / 为什么不够」}}
- 理想状态：{{「理想中是什么样」}}
- 触发事件：{{「为什么现在想解决」}}
- 优先级：{{「这个问题有多紧急」}}

#### 关键问题清单
- 5 个不能不问的问题：{{开放 + 深层}}
- 5 个视情况问的问题：{{基于回答深挖}}

### 4. 价值对齐（5-10 分钟）
- 重述痛点：{{让客户确认「是的」}}
- 价值映射：{{我们能帮到什么}}
- 案例引用：{{相似客户怎么解决}}
- 差异点：{{为什么我们不同}}

### 5. 下一步（5 分钟）
#### 推进选项
- 试用：{{具体步骤 + 时间}}
- Demo：{{个性化演示}}
- 提案：{{基于今天的需求}}
- 对接决策者：{{联系相关人}}

#### 询问
- 「今天聊下来，您觉得我们能帮到您吗？」
- 「下一步您希望怎么走？」
- 「谁还需要参与决策？」

### 6. 收尾
- 总结共识：{{今天确认的 3 件事}}
- 下一步明确：{{具体时间 + 具体动作}}
- 后续沟通：{{节奏 + 方式}}

## 提问技巧
- 开放式问题：{{5W1H}}
- 追问：{{「为什么」「能举个例子吗」}}
- 沉默：{{留白让客户补充}}
- 共情：{{「我理解」「很多客户都遇到过」}}

## 倾听技巧
- 不抢话：{{让客户说完}}
- 复述确认：{{「您是说...」}}
- 情绪关注：{{听出言外之意}}
- 关键信息标记：{{边听边记}}

## 反对意见处理
- 「太贵了」→ 算 ROI 对比
- 「现在没时间」→ 评估优先级
- 「已经有了」→ 差异化对比
- 「需要内部讨论」→ 推动会议

## 通话记录模板
- 客户背景：{{基本信息}}
- 关键痛点：{{3-5 条}}
- 决策因素：{{关键考量}}
- 下一步：{{具体动作 + 时间}}
- 内部跟进：{{团队分工}}

## 写作硬规则
- 通话结构基于真实成单经验
- 提问清单不只 5 个（视情况深挖）
- 价值对齐必须呼应痛点
- 下一步必须具体可执行
- 通话记录必须模板化

## 自检
- [ ] 通话节奏是否清晰
- [ ] 提问是否开放 + 深层
- [ ] 价值是否呼应痛点
- [ ] 下一步是否具体
- [ ] 记录是否模板化
