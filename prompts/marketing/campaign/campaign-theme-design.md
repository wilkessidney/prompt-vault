## 活动主题设计结构
### 1. 主题概念
- **核心概念**：{{一句话讲清是什么活动}}
- **钩子**：{{让人想参与的理由}}
- **情感调性**：{{温暖 / 热血 / 共鸣 / 惊喜}}
- **隐喻意象**：{{贯穿活动的视觉 / 故事元素}}

### 2. 主题表达（多版本）
| 场景 | 主题名 | 副标题 |
|------|--------|--------|
| 官方主推 | {{主标题}} | {{副标题}} |
| 传播变体 | {{钩子标题}} | {{说明}} |
| 落地页 | {{转化标题}} | {{行动号召}} |

要求：
- 主标题 ≤8 字
- 有记忆点（不抽象）
- 口语化不装

### 3. 故事脚本
#### 引入（30 秒）
- 场景 / 痛点 / 期待

#### 展开（2 分钟）
- 故事 / 角色 / 冲突

#### 召唤（30 秒）
- 邀请参与 + 具体动作

### 4. 视觉系统
- 主视觉：{{海报 / KV 设计方向}}
- 配色：{{具体色值}}
- 字体：{{与品牌一致或专属}}
- 元素：{{贯穿活动的图形元素}}

### 5. 互动机制
- 参与方式：{{简单到 3 步可参与}}
- 激励：{{利益 / 情感 / 社交价值}}
- 传播：{{可分享 / 可炫耀 / 可挑战}}

### 6. 时间节点
- 预热期：{{时间 + 节奏}}
- 爆发期：{{时间 + 节奏}}
- 长尾期：{{时间 + 节奏}}

### 7. 渠道分发
- 主渠道：{{公众号 / 抖音 / 线下}}
- 渠道分工：{{触达 / 种草 / 转化}}
- KOL / KOC：{{合作清单}}

### 8. 风险与备选
- 主题冒犯：{{敏感性测试}}
- 竞品撞档：{{差异化点}}
- 舆情风险：{{应急预案}}

## 写作硬规则
- 主题必须有具体意象，不是「赋能」「共赢」
- 钩子必须直击参与动机
- 主标题字数严控（≤8 字）
- 视觉与主题一致
- 互动机制简单（不要复杂规则）
- 风险预案提前准备
