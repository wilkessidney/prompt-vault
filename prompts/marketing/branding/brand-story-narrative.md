## 品牌故事结构
### 1. 故事核心张力
- 我们看到的矛盾：{{行业 / 用户 / 自己}}
- 我们相信不同的：{{信念 / 价值观}}
- 张力让故事有说服力

### 2. 三幕结构
#### 第一幕：起源（建立共情）
- 创始人 / 团队为什么开始
- 当年看到 / 经历了什么
- 让读者共情：「我也遇到过」

#### 第二幕：冲突（建立张力）
- 走过的弯路 / 失败 / 反思
- 关键的转折点
- 失败的代价 / 反思的深度

#### 第三幕：使命（建立召唤）
- 我们学到了什么
- 我们做什么
- 邀请读者一起

### 3. 故事素材选择
- 真实素材：{{从创始人访谈 / 内部史提炼}}
- 戏剧冲突：{{不要平铺直叙}}
- 具体细节：{{某个场景 / 一句话 / 一个数字}}
- 情感触发：{{那一刻的真实感受}}

### 4. 故事节奏
- 起：30 秒建立情境
- 承：1 分钟讲清冲突
- 转：30 秒给出转折
- 合：30 秒召唤行动

### 5. 多版本
#### 30 秒版（电梯 / 视频前 30 秒）
- 起源 + 张力 + 召唤一句话

#### 3 分钟版（发布会 / 介绍视频）
- 三幕结构完整呈现

#### 1 页版（官网 / 招聘）
- 起承转合精简版

#### 长篇版（深度专访 / 品牌书）
- 完整故事 + 背景 + 反思

### 6. 故事应用
- 官网：{{About Us / 品牌故事}}
- 招聘：{{打动候选人的版本}}
- PR：{{媒体可引用的版本}}
- 客户沟通：{{让客户有归属感的版本}}

### 7. 真实性检验
- 每个细节可溯源
- 不编造冲突 / 失败
- 创始人真实参与 / 认可
- 反映品牌核心信念

## 写作硬规则
- 故事必须有真实冲突，不是「一路走来」
- 细节必须具体可感（不是「有一天」）
- 创始人 / 团队真实参与
- 节奏清晰，不堆砌背景
- 多版本针对不同场景
