## 输入
- 社群定位：{{从价值 brief 引用}}
- 目标：{{激活 / 转化 / 留存 / 增长}}
- 资源：{{可提供的差异化权益}}
- 现有用户：{{规模 + 现状}}

## 分层结构
### 1. 分层维度
#### 价值维度
- 贡献度：{{内容 / 引流 / 活跃}}
- 影响力：{{粉丝 / 受关注度}}
- 忠诚度：{{时长 / 续费 / 推荐}}

#### 行为维度
- 参与度：{{互动 / 活动出席}}
- 内容产出：{{UGC / 反馈}}
- 主动连接：{{帮助他人 / 答疑}}

### 2. 分层体系
| 层级 | 名称 | 占比 | 进入条件 | 主要权益 |
|------|------|------|----------|----------|
| L4 | 核心 | 5% | 主动贡献 + 高忠诚 | 核心资源 + 共创机会 |
| L3 | 活跃 | 15% | 高频参与 + 价值 | 深度内容 + 优先权 |
| L2 | 常规 | 50% | 标准参与 | 基础内容 + 活动 |
| L1 | 沉默 | 25% | 偶尔参与 | 唤醒激励 |
| L0 | 流失 | 5% | 90 天未活跃 | 召回机制 |

### 3. 各层权益
#### L4 核心
- 与运营直接对话
- 内测产品 / 共创
- 线下活动主嘉宾
- 行业资源对接
- 现金 / 实物激励

#### L3 活跃
- 优先客服 / 答疑
- 专属内容 / 直播
- 提前参与新活动
- 节日特别礼包

#### L2 常规
- 基础社群内容
- 参与一般活动
- 获得福利机会

#### L1 沉默
- 唤醒内容
- 福利召回
- 限时激活

#### L0 流失
- 调研问卷
- 召回优惠
- 重新激活路径

### 4. 升降级机制
#### 升级路径
- L2 → L3：{{累计 X 次贡献 + Y 月活跃}}
- L3 → L4：{{主动 + 被推荐 + 持续}}
- 升级激励：{{明确 + 即时}}

#### 降级机制
- L4 → L3：{{3 个月不活跃}}
- L3 → L2：{{3 个月不达标}}
- 降级通知：{{提前 + 解释 + 鼓励}}

### 5. 激励体系
#### 物质激励
- 现金红包：{{发放机制}}
- 实物奖品：{{荣誉奖品}}
- 优惠券：{{专属优惠}}
- 周边产品：{{限量版}}

#### 精神激励
- 称号：{{具体 + 稀有}}
- 榜单：{{周榜 / 月榜}}
- 标识：{{专属徽章}}
- 致谢：{{公开 / 私聊}}

#### 社交激励
- 圈层准入：{{高阶圈子}}
- 资源对接：{{人脉 / 合作}}
- 行业曝光：{{大会 / 媒体}}
- 互推：{{其他社群导流}}

### 6. 用户成长路径
- 加入：{{标准化欢迎}}
- 融入：{{找到归属 + 获得价值}}
- 贡献：{{从消费到参与}}
- 影响：{{成为 KOC / KOL}}
- 传承：{{帮助新人 + 文化建设}}

### 7. 数据监控
- 分层结构：{{每层占比}}
- 升降级：{{每月变化}}
- 各层活跃：{{关键指标}}
- 各层价值：{{商业贡献}}

### 8. 风险控制
- 头部用户流失：{{应对机制}}
- 攀比 / 矛盾：{{处理流程}}
- 权益滥用：{{监督机制}}
- 公平性：{{避免不公感知}}

## 写作硬规则
- 分层维度基于社群特性（不照搬）
- 各层权益差异化明显（不只是数字）
- 升降级机制清晰可执行
- 激励体系覆盖物质 / 精神 / 社交
- 风险控制前置设计

## 自检
- [ ] 维度是否基于社群特性
- [ ] 权益是否差异化
- [ ] 升降级是否清晰
- [ ] 激励是否全面
- [ ] 风险是否前置
