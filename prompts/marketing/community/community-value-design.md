## 社群价值设计结构
### 1. 社群定位
- **社群使命**：{{用户加入能得到什么}}
- **社群边界**：{{明确服务的对象}}
- **社群调性**：{{温暖 / 专业 / 干货 / 陪伴}}
- **差异化**：{{与同类社群的不同}}

### 2. 价值主张
#### 显性价值
- 内容价值：{{独家 / 深度 / 实时}}
- 资源价值：{{对接 / 福利 / 优惠}}
- 服务价值：{{答疑 / 咨询 / 陪伴}}
- 社交价值：{{人脉 / 同好 / 归属}}

#### 隐性价值
- 情绪价值：{{陪伴 / 共鸣 / 被看见}}
- 身份价值：{{会员 / 稀缺 / 圈层}}
- 成长价值：{{学习 / 提升 / 进阶}}

### 3. 价值供给机制
#### 内容供给
- 每日 / 每周内容：{{具体形式}}
- 原创 + 转载比例：{{基于团队产能}}
- 内容选题：{{基于用户需求}}
- 内容节奏：{{稳定 + 惊喜}}

#### 互动供给
- 每日话题：{{具体 + 易参与}}
- 每周活动：{{打卡 / 分享 / 直播}}
- 每月大事件：{{线下 / 大咖 / 福利}}
- 每季度升级：{{新产品 / 新权益}}

### 4. 用户旅程
#### 加入前
- 触达：{{在哪里看到}}
- 期待管理：{{明确说明能获得什么}}
- 加入理由：{{具体钩子}}

#### 加入初期（首 7 天）
- 欢迎：{{标准化 + 温度}}
- 引导：{{快速融入 + 找到归属}}
- 首次价值：{{24 小时内获得感}}
- 关系建立：{{认识人 / 找到组织}}

#### 活跃期
- 日常价值：{{稳定输出}}
- 互动参与：{{融入社群}}
- 贡献者激励：{{成为 KOC}}
- 成长路径：{{从成员到 KOC 到 KOL}}

#### 留存期
- 持续惊喜：{{新权益 / 新内容}}
- 情感连接：{{仪式感 / 专属}}
- 价值升级：{{从消费到参与}}
- 长期关系：{{变成朋友 / 家人}}

### 5. 用户分层运营
- **核心用户**：{{KOC 培养}}
- **活跃用户**：{{激励 + 反馈}}
- **沉默用户**：{{激活 / 召回}}
- **流失用户**：{{调研 / 挽回 / 放弃}}

### 6. 社群文化
- 价值观：{{明确表达}}
- 行为规范：{{欢迎什么 / 不欢迎什么}}
- 仪式感：{{早晚安 / 节日 / 生日}}
- 共同记忆：{{梗 / 故事 / 关键节点}}

### 7. 运营节奏
- 日节奏：{{早中晚内容 + 互动}}
- 周节奏：{{周话题 + 周复盘}}
- 月节奏：{{月度活动 + 福利}}
- 季度节奏：{{大事件 + 升级}}

### 8. 数据监控
- 活跃指标：{{发言 / 留存 / 邀请}}
- 价值指标：{{满意度 / NPS}}
- 商业指标：{{转化 / 续费 / 复购}}
- 健康指标：{{文化认同 / 归属感}}

### 9. 持续创新
- 新形式尝试：{{直播 / 挑战 / 共创}}
- 用户共创：{{UGC 收集 / 反馈采纳}}
- 跨界合作：{{与其他社群联动}}
- 季度升级：{{基于反馈优化}}

## 写作硬规则
- 价值主张必须具体可感（不是「学习」「成长」）
- 内容供给基于团队产能（不承诺做不到的）
- 用户旅程覆盖全生命周期
- 用户分层运营避免一刀切
- 社群文化必须有仪式感

## 自检
- [ ] 价值主张是否具体可感
- [ ] 供给是否基于团队产能
- [ ] 旅程是否覆盖全周期
- [ ] 分层运营是否到位
- [ ] 文化是否有仪式感
