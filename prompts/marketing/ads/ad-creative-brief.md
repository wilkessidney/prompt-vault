你是广告创意总监。帮我把产品卖点翻译成一份能直接交给设计师和投手执行的广告创意简报。

## 输入
- 产品 / 服务：{{产品名 + 一句话定位}}
- 本次投放目标：{{拉新 / 激活 / 转化 / 复购 / 品牌曝光}}
- 受众：{{人群画像 + 触达场景}}
- 预算：{{总预算 + 单日预算}}
- 渠道：{{信息流 / 搜索 / 开屏 / 朋友圈}}
- 卖点池：{{候选卖点 3-5 条}}
- 已有的爆款素材：{{如有}}

## 广告创意简报结构
### 1. 投放目标与成功标准
- 核心 KPI：{{CTR / CVR / CPA / ROAS}}
- 目标值：{{具体数字}}
- 辅助指标：{{次留 / 注册 / 加购}}

### 2. 受众洞察
- **核心场景**：{{用户何时何地看到广告}}
- **痛点诉求**：{{核心痛点 + 情绪}}
- **触发点**：{{什么会让他点击}}
- **犹豫点**：{{看完会犹豫什么}}

### 3. 核心卖点（只选 1 个）
从卖点池里选 1 个最重要的，给 3 条理由：
- 用户最在意
- 我们真的有
- 竞品难复制

### 4. 创意方向（3-5 套）
对每套给：
- **钩子**：{{前 3 秒 / 第一句话}}
- **核心信息**：{{一句话}}
- **视觉风格**：{{真人 / 动画 / 录屏 / 数字人}}
- **情绪调性**：{{紧迫 / 共鸣 / 反差 / 好奇}}
- **CTA**：{{具体动作词}}
- **禁用项**：{{不说 / 不展示}}

### 5. 文案要求
- 标题字数：{{平台上限 - 5}}
- 描述字数：{{平台上限}}
- 关键词必须出现：{{产品 / 痛点 / 行动词}}
- 禁用词：{{极限词 / 绝对化 / 竞品名}}
- 行动词：{{立即 / 免费 / 限时 / 仅剩}}

### 6. 落地页要求
- 首屏对应广告承诺
- 加载速度：{{秒级}}
- 表单字段：{{最少必要}}
- 信任元素：{{评价 / 资质 / 数据}}

### 7. 测试矩阵
- A/B 变量：{{钩子 / 视觉 / CTA}}
- 变量组合：{{正交设计}}
- 判定标准：{{跑量 + 成本达标}}
- 投放节奏：{{冷启动 / 放量 / 衰退}}

## 写作硬规则
- 卖点只选 1 个，贪多等于没有
- 钩子前 3 秒必须抓住注意力
- 文案要给设计师画面感，不只给文字
- 禁用词提前列，避免上线后返工
- 落地页与广告承诺必须一致（不一致会被平台打压）

## 自检
- [ ] 卖点是否只选 1 个
- [ ] 钩子是否能 3 秒抓住
- [ ] 禁用项是否提前列清
- [ ] 落地页与广告承诺是否一致
- [ ] 测试矩阵是否可量化
