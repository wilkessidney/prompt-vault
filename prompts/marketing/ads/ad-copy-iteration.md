## 迭代框架

#### 曝光层
- CTR 高于 / 低于行业基准：{{具体 + 行业值}}
- 原因假设：{{素材吸引力 / 人群精准度 / 时段}}
- 验证动作：{{A/B 测试}}

#### 点击层
- 点击率：{{具体}}
- 高于行业基准：素材好，加大投放
- 低于基准：素材问题

#### 转化层
- CVR：{{具体}}
- 高于基准：流量精准，继续放量
- 低于基准：落地页问题
- 优化方向：{{落地页 / 受意图 / 优惠}}

#### 成本层
- CPA：{{具体 vs 目标}}
- ROAS：{{具体 vs 目标}}
- 优化方向：{{提高 CVR / 降低 CAC / 提价}}

### 4. 测试设计
- 一次只改一个变量
- 流量分配：{{50 / 50 或 80 / 20}}
- 判定时长：{{至少 7 天 / 1000 转化}}
- 上线 / 下线标准

### 5. 复盘机制
- 每天：盯数据，发现异常立即下线
- 每周：复盘所有素材
- 每月：更新素材库（保留头部 / 淘汰尾部）

## 写作硬规则
- 一次只改一个变量，不要多变量混淆
- 假设要具体（不是「素材不好」）
- 数据有对照组，不要凭感觉
- 至少 1000 转化下结论，少量数据不判断
- 复盘动作必须形成闭环

- [ ] 诊断是否基于数据，不是感觉
