## 输入
- 产品：{{产品名 + 核心价值}}
- 落地页目标：{{注册 / 试用 / 购买 / 加购 / 留资}}
- 流量来源：{{广告 / 邮件 / 搜索 / 推荐}}
- 受众认知阶段：{{不知道 / 知道 / 考虑 / 决策}}
- 主要竞品落地页：{{参考点}}

## 落地页结构
### 1. 首屏（3 秒定生死）
- **承诺**：{{用户视角的具体收益}}
- **对比**：{{比现状好在哪里}}
- **行动按钮**：{{动词 + 收益}}

### 2. 痛点放大
- 3 个具体场景：{{用户当下的痛}}
- 不解决的后果：{{时间 / 成本 / 机会}}
- 让用户点头：「是的，我就是这个情况」

### 3. 解决方案
- 一句话方案：{{非专业人能懂}}
- 核心机制：{{为什么能解决}}
- 差异化：{{不只是「更好」，是「不同」}}

### 4. 信任元素
- 用户案例：{{3 个不同场景的真实客户}}
- 数据：{{注册数 / 客户数 / 增长率}}
- 资质：{{媒体报道 / 行业奖项 / 安全认证}}
- 客户Logo：{{知名客户}}

### 6. 功能详解
- 3-5 个核心功能
- 每个：{{解决什么问题 + 用户得到什么}}
- 截图 / 视频 / 演示

### 7. 价格与套餐
- 3 层定价（锚定 + 诱饵）
- 推荐套餐视觉强调
- 「隐藏选项」或「联系销售」承接高价

### 8. FAQ
- 5-8 个真实会被问到的问题
- 包含价格 / 数据 / 集成 / 退款 / 迁移

### 9. 风险反转
- 退款承诺
- 免费试用
- 数据安全

### 10. 终极 CTA
- 重复核心承诺
- 紧迫感：{{限时 / 限量}}
- 多个 CTA 入口

## 文案硬规则
- **每个模块必须有转化目的**，不堆砌信息
- 标题用「你」不用「我们」，用收益不用功能
- 痛点要具体到场景，不抽象
- 案例必须真实可溯源
- 价格透明，不藏猫腻
- 行动按钮动词 + 收益，不只「提交」

## 视觉与交互
- 加载速度：≤3 秒
- 移动端优先
- 滚动引导：{{从首屏到 CTA 的视觉引导}}
- 表单字段：≤5 个
- 实时聊天 / 留言入口

- [ ] 首屏能否 3 秒内讲清价值

- [ ] 是否所有模块都有转化目的
