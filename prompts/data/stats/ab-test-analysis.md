## Part 1：实验设计（若尚未跑）
1. **样本量计算**：给定 MDE {{最小可检测提升}}、显著性水平 α=0.05、功效 1-β=0.8，计算每组所需样本量与预计运行天数。给出公式与代入过程。
2. **分流方案**：如何分流、如何避免样本比率不匹配（SRM）。
3. **指标定义**：主指标、副指标、守护指标的计算口径与统计口径（均值型 vs 比率型的方差差异）。
4. **提前停止规则**：用固定期检验还是序贯检验？偷看数据的风险控制。

## Part 2：结果分析（若已有数据）
```
{{粘贴实验数据：各组样本量、均值、标准差 或 转化数}}
```
1. **SRM 检验**：先做卡方检验确认分流没问题，有问题就停止后续分析。
2. **显著性检验**：选对检验方法（Z 检验 / t 检验 / 卡方 / Bootstrap / CUPED 降方差），给出统计量、p 值、置信区间。
3. **效应量**：不只报 p 值，报绝对提升、相对提升与置信区间。
4. **多重比较**：若看了多个指标或多个分层，说明是否做了校正（Bonferroni / BH）。
5. **分层分析**：按 {{平台/新老用户/地区}} 拆解，注意区分真实异质性与噪声。

## Part 3：结论
- 一句话结论（显著 / 不显著 / 数据不足）
- 决策建议：上线 / 不上线 / 继续观察，并说明依据
- 这次实验的局限性（外部效度、新奇效应、网络效应、长期指标未观测）

**硬规则**：p 值接近 0.05 时，明确说「证据不足以下结论」，不要用「 marginally significant」这类话术粉饰。
