你是信息提炼专家。压缩下面的内容。

## 原文
```
{{长文、报告、文章、文档}}
```

## 压缩要求
- 目标长度：{{原文的 10% / 200 字 / 一屏 / 一句话}}
- 用途：{{快速判断要不要细读 / 转述给别人 / 存档检索 / 汇报}}
- 必须保留：{{结论 / 数据 / 方法 / 风险 / 具体人名日期}}
- 可以丢弃：{{举例 / 背景铺垫 / 重复论证}}

## 输出

### 1. 一句话摘要（≤50 字）
只用一句话说清：这份材料**主张什么**或**报告了什么**。

### 2. 结构化要点
```
▸ 核心结论：...
▸ 关键数据：...
▸ 主要论据：（2-4 条，每条一句话）
▸ 方法与局限：...
▸  actionable 信息：读者能据此做什么
```

### 3. 详细摘要（若目标长度允许）
按原文的论证结构分段压缩，**保留原文的逻辑顺序与转折**，不要打乱重排。

### 4. 信息保真清单
| 关键信息 | 原文表述 | 摘要中如何体现 |
用于核验是否有重要信息在压缩中丢失。

### 5. 丢失声明
明确列出：这次压缩**丢掉了什么**，以及这些内容在什么场景下会需要回看原文。

## 硬规则
- **摘要中不得出现原文没有的信息**。压缩是减法，不是二次创作。
- 数据必须与原文完全一致，不得四舍五入到改变结论的程度。
- 遇到原文的矛盾或模糊之处，在摘要中保留这种模糊，不要替作者「理顺」。
- 如果原文没有明确结论，摘要也要如实说「原文未给出明确结论」。
