## 冷邮件自动化结构
### 1. 战略层
#### 目标设定
- 发送量目标
- 回复率目标
- 转化率目标
- 投资回报

#### 受众分层
- Tier 1：{{高价值 + 少而精】
- Tier 2：{{中价值 + 中等数量}}
- Tier 3：{{大量测试}}

### 2. 内容层
#### 邮件模板
- 第 1 封：{{开场 + 价值 + CTA}}
- 第 2 封：{{不同角度 + 价值 + CTA}}
- 第 3 封：{{紧迫 + 价值 + CTA}}
- 第 4 封：{{资源 + 无压力}}
- 第 5 封：{{最终 + 优雅告别}}

#### 个性化变量
- 姓名
- 公司
- 角色
- 痛点
- 触发事件
- 推荐来源

### 3. 数据层
#### 联系人列表
- 来源：{{LinkedIn / 行业活动 / 数据库}}
- 字段：{{邮箱 + 姓名 + 公司 + 角色 + 来源}}
- 质量：{{验证邮箱 + 去重}}
- 合规：{{同意 + 来源}}

#### 数据清洗
- 邮箱验证
- 去重
- 更新
- 分类

### 4. 工具层
#### 邮件自动化工具
- Lemlist：{{个性化 + 自动化}}
- Mailshake：{{外联 + 跟进}}
- Reply.io：{{多渠道外联}}
- Smartlead：{{发送 + 优化}}
- Apollo：{{B2B 数据 + 外联}}
- 国内：{{SendCloud / 邮件易}}

#### CRM 集成
- HubSpot
- Salesforce
- Pipedrive
- 国内：{{销售易 / 纷享销客}}

### 5. 发送层
#### 发送策略
- 域名设置：{{主域 + 子域}}
- SPF / DKIM / DMARC 配置
- IP 预热
- 发送量渐增

#### 发送节奏
- 周二到周四
- 上午 9-11 点
- 下午 14-16 点
- 避免周一 / 周五

#### 频率
- 每周 1-2 封
- 不轰炸
- 给回复时间

### 6. 个性化层
#### 模板变量
- 基本变量：{{姓名 + 公司 + 角色}}
- 高级变量：{{最近动态 + 共同点 + 推荐人}}
- 动态变量：{{行业 + 痛点 + 价值}}

#### 合并字段
- 不止 {{First Name}}
- 真实个性化
- 基于研究

### 7. 跟进层
#### 自动跟进
- 第 1 封未回 → 第 2 封（3 天后）
- 第 2 封未回 → 第 3 封（7 天后）
- 第 3 封未回 → 第 4 封（14 天后）
- 第 4 封未回 → 第 5 封（21 天后）

#### 跟进逻辑
- 不同角度
- 不同价值
- 不重复
- 给退出

### 8. 追踪层
#### 邮件追踪

- 点击率
- 回复率
- 退订率

#### 数据分析

- 受众分层效果
- 时间 / 频率效果
- 个性化效果

#### A/B 测试
- 主题行
- 开头
- CTA
- 时间

- 跟踪状态

- 回复 → 演示
- 回复 → 试用
- 回复 → 决策

### 10. 合规层
