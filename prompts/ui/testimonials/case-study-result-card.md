Build a case study proof block with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}. Use a max-w-5xl grid of two cards on lg, each a bordered rounded-2xl white card split into an upper quote area and a lower results strip. The upper area holds a small customer wordmark in muted uppercase, a pull quote of two sentences in larger relaxed type with the key clause wrapped in a span carrying a neutral-100 highlight, and an attribution row with an avatar circle, a name in medium weight and a role line. The lower strip is a neutral-50 area divided into three cells by vertical hairlines, each with a large figure, a tiny uppercase label and an arrow glyph coloured green for improvements. End each card with a footer link reading "Read the full story" and an arrow. Include two examples with different industries and different metric sets.
