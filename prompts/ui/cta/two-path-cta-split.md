Build a two-path call to action with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}: two side-by-side cards offering different next steps. The left card is dark and self-serve — heading, one line of copy, a white button, and a small note about no credit card. The right card is white with a border and sales-led — heading, copy, an outline button, and a line about typical response time. Give each card a small label chip at the top and equal height with flex.

Deliver the result as {{输出格式：单个 HTML 文件（内联 style 与 script） / React 组件（.tsx） / Vue 单文件组件（.vue） / Astro 组件（.astro）}}.
