Design a partnership enquiry form with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}. Use a max-w-2xl card with a heading, a paragraph naming the three kinds of partnership on offer, and a form. The fields are: partnership type as three selectable tiles with glyphs — technology integration, reseller, and co-marketing; company name and website side by side; contact name and work email side by side; a budget or deal size select with five ranges and a "not sure yet" option; a timeline select; and a textarea for what they have in mind with a helper line asking for one specific outcome. Under the fields, a checkbox agreeing to be contacted, a dark submit button and a muted line stating that unqualified enquiries still get an answer, just a slower one. Add a right-aligned small note giving the current response time.

Deliver the result as {{输出格式：单个 HTML 文件（内联 style 与 script） / React 组件（.tsx） / Vue 单文件组件（.vue） / Astro 组件（.astro）}}.
