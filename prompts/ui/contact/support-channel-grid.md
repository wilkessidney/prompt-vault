Build a support routing section with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}: a centered heading and subline, then a grid of three or four channel cards. Each card has an icon tile, a channel name, a one-line description, a response-time line in muted text, and an action link with an arrow; give one card a live-chat status chip with a green dot and another a muted "Offline until 9am" chip. Cards lift on hover with a shadow, and the grid collapses to one column on mobile.

Deliver the result as {{输出格式：单个 HTML 文件（内联 style 与 script） / React 组件（.tsx） / Vue 单文件组件（.vue） / Astro 组件（.astro）}}.
