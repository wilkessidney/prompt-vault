Build a brand-voice calibration onboarding step with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}. Present four pairs of alternative microcopy where the user chooses which version sounds more like the brand. Include progress, skip, back, and continue controls plus a live voice profile that updates across dimensions such as direct, warm, technical, and playful. Add JavaScript that records one choice per pair, updates the profile bars, and enables Continue only after every pair has an answer.

Deliver the result as {{输出格式：单个 HTML 文件（内联 style 与 script） / React 组件（.tsx） / Vue 单文件组件（.vue） / Astro 组件（.astro）}}.
