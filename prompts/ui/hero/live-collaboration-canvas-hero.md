Build a live-collaboration hero with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}. Pair a concise product headline and two CTAs with a large canvas mockup containing sticky notes, connectors, participant avatars, and labeled remote cursors. Add a presence line and a compact activity ticker. Use JavaScript to move the cursors gently around the canvas, cycle the activity message, and pause animation when reduced motion is preferred.
