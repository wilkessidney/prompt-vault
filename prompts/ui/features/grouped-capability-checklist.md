Create a dense feature index with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}: four grouped columns, each with a small uppercase group label and a list of short capability items marked with a subtle check glyph. Above the columns place a heading, a one-line intro, and a link to full documentation. Keep the type small, the rows tight, and collapse to two columns on md and one on mobile — the goal is to communicate breadth at a glance.

Deliver the result as {{输出格式：单个 HTML 文件（内联 style 与 script） / React 组件（.tsx） / Vue 单文件组件（.vue） / Astro 组件（.astro）}}.
