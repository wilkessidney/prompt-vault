Build a platform support matrix with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}. Above the table, a heading, a muted subline, and a legend of three small items — available, partial and planned — each with its marker. The table has a feature column and four platform columns with icon-and-label headers for Web, iOS, Android, Desktop and CLI. Include eight feature rows covering dashboards, editing, offline mode, notifications, exports, admin settings, SSO login and scripting. Cells hold a green check for full support, an amber half-circle glyph with a small "partial" label under it for limited support, a muted dash for unsupported, and a small "Q4" pill for planned items. Zebra-stripe alternate rows very faintly, make the first column sticky on horizontal scroll, and wrap the table in a container that scrolls sideways on small screens. Under it, a footnote about the minimum OS versions.

Deliver the result as {{输出格式：单个 HTML 文件（内联 style 与 script） / React 组件（.tsx） / Vue 单文件组件（.vue） / Astro 组件（.astro）}}.
