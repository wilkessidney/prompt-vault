Design a security and compliance section with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}. Open with a small "Trust" label, a heading and a supporting paragraph. Then a row of four certification tiles — SOC 2 Type II, ISO 27001, GDPR and HIPAA — each a bordered rounded-xl card with a shield glyph, the standard name in medium weight, a muted line giving the audit date or status, and a tiny green "Current" pill. Below the tiles, a two-column grid of six control rows, each with a check glyph, a bold control name and a muted sentence; cover encryption at rest and in transit, single sign-on, key rotation, penetration testing, data residency and backups. Close with a dark full-width strip inviting people to the trust centre, holding a short line of copy on the left and two buttons on the right — a white primary for the trust centre and a ghost outline for requesting the latest report.

Deliver the result as {{输出格式：单个 HTML 文件（内联 style 与 script） / React 组件（.tsx） / Vue 单文件组件（.vue） / Astro 组件（.astro）}}.
