Build a query-performance workbench with {{技术栈：Tailwind CSS / 原生 CSS / UnoCSS / styled-components}}. Include database and time-range filters, p95 latency and throughput metrics, a ranked query table with calls, rows, duration, and trend, plus a detail panel showing the selected SQL, execution-plan steps, and a recommendation. Add JavaScript that selects rows, updates the detail panel from data, and filters to slow queries only.

Deliver the result as {{输出格式：单个 HTML 文件（内联 style 与 script） / React 组件（.tsx） / Vue 单文件组件（.vue） / Astro 组件（.astro）}}.
