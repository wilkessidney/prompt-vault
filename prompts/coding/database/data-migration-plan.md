为下方需求设计数据迁移方案。

## 需求
- 迁移内容：{{表 / 库 / 分库分表 / 换存储引擎}}
- 数据量：{{数据量}}
- 停机窗口：{{能否停机 / 最大容忍}}
- 一致性要求：{{强一致 / 最终一致可接受分钟级}}

## 输出
### 1. 迁移架构图
存量怎么搬（全量 + 增量 binlog/cdc）、新写入怎么处理（双写 or 切流）。

### 2. 分阶段执行计划
阶段 | 动作 | 验证标准 | 回滚方式 | 预计耗时。至少含：准备、全量、增量追平、灰度读、灰度写、全量切换、观察期、收尾。

### 3. 数据校验
行数对账 + 抽样字段比对 + 实时 diff 监控的具体做法。

### 4. 风险与预案
每个阶段失败时的止血动作（必须具体到命令级思路）。

**硬规则**：任何阶段都必须可回滚；切换动作必须有 checklist。
