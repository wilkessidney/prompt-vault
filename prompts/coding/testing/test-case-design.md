## 设计方法（必须用上）
1. **等价类划分**：把输入分成若干类，每类取一个代表值。
2. **边界值分析**：对每个数值/长度边界，取 min-1、min、min+1、正常、max-1、max、max+1。
3. **错误推测**：基于经验猜测容易出错的地方（空值、特殊字符、时区、浮点精度、编码）。
4. **状态转换**：若涉及状态机，覆盖所有合法转换 + 至少 2 条非法转换。
