## 输出
1. **最小化**：剥离复现步骤里不必要的条件，找出触发 bug 的最小输入（说明你排除了什么）。
2. **失败的测试**：先写一个当前会失败（红）的测试，精确断言期望行为。
3. **触发条件分析**：这个 bug 的触发窗口是什么（特定输入/状态/时序），有没有相邻的未触发变体也该测。
4. **回归防线**：修复后，这个测试之外还应加什么测试防止同类问题（同族 bug 检查）。
5. **修复建议**：如果你能定位根因，给出修复方向（但测试不依赖你的修复假设）。

**硬规则**：测试必须稳定复现（偶发 bug 先想办法去随机化）；断言的是「期望行为」而非「当前行为」。
