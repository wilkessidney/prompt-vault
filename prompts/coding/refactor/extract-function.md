## 原则
- 每次抽取一个内聚块，函数名 = 它做的事（动词开头）。
- 抽取后主函数应该读起来像目录/大纲。
- 中间变量变成参数或返回值时，命名要暴露数据流向。

## 输出
1. **切块方案**：先标出代码里的逻辑块及边界（注释形式），说明每块的职责。
2. **重构后代码**：完整、可直接替换原函数。
3. **重构对照**：新函数名 | 职责 | 从原函数第几行到第几行。
4. **行为不变性检查**：哪些点容易在抽取时悄悄改变行为（副作用顺序、提前 return、异常传播），逐条确认没变。

**硬规则**：纯重构，不修 bug 不改算法；发现原代码问题列在最后「顺带发现」一节，不动手。
