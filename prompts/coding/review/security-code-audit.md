## 上下文
- 暴露面：{{对外接口 / 内部服务 / 定时任务}}
- 数据敏感度：{{涉及的数据：用户 PII / 支付 / 普通业务}}

## 输出
### 1. 漏洞清单
按 OWASP 类别扫描（注入、失效的访问控制、加密失败、SSRF、反序列化、XXE、CSRF、日志泄漏敏感信息……与该代码相关的都查）：

漏洞 | 位置 | 攻击场景（具体到攻击者怎么利用） | 严重度（CVSS 思路） | 修复代码

### 2. 信任边界标注
哪些输入来自不可信方，传播路径上哪里做了校验，哪里裸奔。

### 3. 加固建议
即使没有直接漏洞，也给出纵深防御建议（最小权限、参数化查询、输出编码、速率限制）。

**硬规则**：每个漏洞必须有具体攻击场景，禁止「可能存在风险」这种废话；修复代码要能直接用。
