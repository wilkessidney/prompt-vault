帮我解读这个正则：

```
{{正则表达式}}
```

（用途线索：{{在什么代码/场景里见到的，可选}}）

## 输出
1. **一句话功能**：这个正则整体在干什么。
2. **结构拆解**：按语法单元拆成树/表格：片段 | 含义 | 捕获组编号或名字。
3. **执行过程**：拿一个典型输入 {{样例输入}}，走一遍匹配过程（哪个字符在哪一段被吃掉）。
4. **边界行为**：空串能过吗？贪婪匹配会吃多少？
5. **潜在问题**：误伤/漏配风险、性能隐患，以及更清晰的替代写法（如有）。

**硬规则**：绝不猜。如果方言不明确会改变语义（如 \d 是否含全角），明确指出并两种都解释。
