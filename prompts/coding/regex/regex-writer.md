帮我写正则表达式。

## 需求
- 匹配目标：{{想匹配什么}}
- 必须匹配的样例：{{应命中的字符串}}
- 必须不匹配的样例：{{不应命中的字符串}}
- 方言：{{JavaScript / Python / PCRE / grep}}

## 输出
1. **正则**：优先给可读的（带命名分组/注释），再给紧凑版。
2. **逐段解释**：每个元字符/分组在干什么，用表格。
3. **测试矩阵**：对上面每个样例标注命中/不命中 + 捕获组内容。
4. **性能与坑**：有没有回溯风险？贪婪还是懒惰更合适？多行/大小写标志要不要？

**硬规则**：如果有多个合理粒度（宽匹配 vs 严匹配），两个都给并说明取舍；不要只给一个「万能但不精确」的。
