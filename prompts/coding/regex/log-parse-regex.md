## 输出
1. **格式分析**：先归纳这套日志的格式规律（定界符、可选字段顺序、异常堆栈怎么多行续接）。
2. **正则**：命名分组版 + 逐组说明。
3. **解析代码**：目标语言里把每行转成 dict/对象的完整片段，处理：
   - 匹配失败的行怎么处理（跳过并计数？进 dead letter？）
   - 多行堆栈怎么归并到上一条
4. **容错测试**：构造 3 条畸形日志（缺字段、空消息、超长行）验证不崩。

**硬规则**：宁可窄匹配也不要让一行脏日志拖垮整个解析任务。
