为下方接口写 API 文档。

## 接口信息
- 接口名与用途：{{接口说明}}
- 方法与路径：{{METHOD /path}}
- 请求参数：{{参数表或代码定义}}
- 响应结构：{{响应结构或示例}}
- 错误码：{{错误码列表}}

## 输出
1. **一句话说明**：这个接口干什么，什么时候该用它（以及什么时候不该用）。
2. **请求**：参数表格（名称 | 类型 | 必填 | 默认 | 说明 | 约束），每个参数说明「写错了会怎样」。
3. **curl 示例**：一个最小请求 + 一个带可选参数的完整请求。
4. **响应**：成功响应示例 + 每个字段的含义；重点字段标注单位与格式（时间戳秒/毫秒、金额单位）。
5. **错误示例**：每个错误码一个真实响应体 + 用户该怎么处理。

**硬规则**：示例必须是合法可复制的；含糊参数（如「状态」）必须列出全部枚举值。
