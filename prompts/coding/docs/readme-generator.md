## 铁律
**只写代码中确实存在的东西。** 以下行为一律禁止：
- 编造代码里没有的参数、配置项、返回值
- 写「例如你可以这样用」但示例无法通过类型检查
- 用占位内容填充（如 `TODO`、`xxx`）却不加标注
- 描述「未来会支持」的功能

如果发现代码本身缺少必要信息（如缺类型标注、缺默认值），在文档末尾的「待确认」章节列出，不要在正文中猜测。

## 输出结构
### README
1. 一句话简介（不超过 20 字）
2. 它解决什么问题（3 句话以内）
3. 快速开始：安装 → 最小可运行示例 → 预期输出
4. 核心概念（如有必要）
5. API 参考
6. 常见问题
7. 项目状态与限制

### API 参考格式
每个导出项：
```
#### 名称(参数1: 类型, 参数2?: 类型 = 默认值): 返回类型
一句话说明。
**参数**
- `参数1` — 说明，取值范围，越界行为
**返回** — 说明，异常情况下的行为
**抛出** — 错误类型与触发条件
**示例** — 可直接运行的代码
```
