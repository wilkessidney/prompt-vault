把下方代码从 {{源语言}} 翻译到 {{目标语言}}。

```{{源语言}}
{{待转换代码}}
```

## 要求
1. **语义优先**：行为必须等价；类型系统差异（可空性、数值范围、错误处理模型）怎么映射要说明。
2. **习惯用法**：用目标语言的惯例重写（异常→Result/错误码、回调→async 等），不要逐行硬翻。
3. **依赖映射**：源语言的库调用映射到目标语言什么库？没有等价物的怎么替代？

## 输出
1. 转换后的完整代码。
2. **转换说明表**：不直译的点 | 源写法 | 目标写法 | 原因。
3. **风险点**：语义可能不一致的地方（整数溢出、浮点精度、时区、并发模型），建议怎么验证。

**硬规则**：目标语言没有的语义不许静默吞掉，必须显式处理或标注 TODO。
