帮我排查内存泄漏。

## 现象
- 运行时：{{Node / JVM / Python / Go}}
- 症状：{{RSS 持续上涨 / OOM / GC 频繁}}
- 增长曲线：{{多久涨多少}}
- 可疑改动：{{最近新增的功能或依赖}}

## 输出
### 1. 经典嫌疑清单
按该运行时列 top 嫌疑（全局缓存无上限、闭包持有大对象、事件监听器未解绑、定时器泄漏、ClassLoader 泄漏等），每条配「怎么验证」。

### 2. 取证步骤
堆快照怎么打（命令级）、两次快照怎么 diff、怎么按「保留大小」排序找嫌疑对象、怎么从引用链找到泄漏源。

### 3. 修复方案
针对最可能的 1-2 个嫌疑给出代码级修复（LRU 上限、WeakRef、显式清理、解绑）。

### 4. 防回归
内存基线监控 + 阈值告警建议。

**硬规则**：区分「泄漏」和「还没到 GC 时机的高水位」；修复前先给取证方法。
