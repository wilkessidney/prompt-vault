为 {{服务名}} 生成线上故障应急手册（runbook）。

## 服务信息
- 功能：{{服务做什么}}
- 技术栈与依赖：{{技术栈 + 依赖的中间件}}
- 部署形态：{{部署方式与实例数}}
- 核心指标：{{关键 SLI}}

## 输出
### 1. 故障分级
P0-P3 判定标准（对用户的影响描述，不用内部术语），各级响应时限。

### 2. 快速诊断树
「告警响了 → 先看哪 3 个 dashboard → 分支判断 → 各分支的定位动作」，画成流程图（Mermaid）。

### 3. 止血动作库
场景 | 动作 | 命令/入口 | 风险 | 需要谁的审批。至少覆盖：回滚、扩容、降级开关、限流、重启。

### 4. 升级路径
什么情况找谁（值班表模板），通知模板（对内 + 对用户）。

### 5. 复盘要求
故障后多长时间内产出什么。

**硬规则**：所有止血动作必须「先保用户，再查原因」；每个动作注明风险。
