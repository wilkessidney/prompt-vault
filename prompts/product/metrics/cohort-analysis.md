你是数据分析师。帮我做一份同期群分析。{{产品 + 关注指标 + 时间窗口}}

## 输入
- 产品：{{产品名 + 用户规模}}
- 关注的指标：{{留存 / 付费 / 内容消费 / 复购}}
- 时间窗口：{{过去 N 个月}}
- 用户分群维度：{{按注册周 / 按获客渠道 / 按首日行为}}

## 同期群分析结构
1. **同期群定义**：明确「同一群」如何划分（注册周 / 渠道 / 行为）
2. **指标定义**：明确的留存 / 付费 / 复购定义（如 D7 留存 = 注册第 7 天回访的用户）
3. **同期群表**：横向 = 注册同期群（每周一群），纵向 = 第 N 天/N 周/N 月
4. **关键观察**：
   - 哪些同期群留存更高 / 更低
   - 趋势：同期群留存是在改善还是恶化
   - 拐点：第几天 / 第几周开始稳定
5. **行动建议**：基于观察到的模式给 3 条具体改进

## 输出
- 同期群留存表（带可视化描述）
- 同期群付费率表
- 趋势对比（新旧同期群对比）
- 关键发现 3-5 条
- 行动建议 3 条

## 写作硬规则
- **每个数字带同期群和时间维度**：「2024-W12 注册用户在 D30 留存 18%」
- 不平均化处理（不要写「平均留存 25%」）
- 同期群数量 ≥10 个（每周一群，10 周以上）
- 时间窗口覆盖完整周期（不能只看最近 4 周）
- 区分同期群差异的原因（产品改动 / 渠道变化 / 季节性）
- 不写「留存率有待提高」这种无信息结论

## 自检
- [ ] 同期群定义是否清晰可重复
- [ ] 时间窗口是否覆盖完整周期
- [ ] 是否识别了趋势（改善 / 恶化）
- [ ] 行动建议是否具体可执行
