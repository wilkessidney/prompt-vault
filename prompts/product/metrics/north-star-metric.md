你是指标架构师。帮我为一个产品选定北极星指标。{{产品 + 阶段 + 当前指标混乱}}

## 输入
- 产品：{{产品名 + 阶段（PMF / 增长 / 成熟 / 衰退）}}
- 当前指标体系：{{已有指标 + 不聚焦 / 没人看 / 互相矛盾的问题}}
- 团队当前最关注的指标：{{DAU / GMV / 留存 / 付费率 / NPS}}
- 核心价值：{{产品为用户提供的根本价值}}

## 北极星指标选定标准
1. **反映核心价值**：用户获得价值时，这个指标必涨
2. **领先于收入**：指标涨，收入会跟着涨（中间可能有滞后）
3. **可被团队影响**：团队可以做事推动它
4. **可被清晰定义**：没有歧义，全公司一个数字
5. **不是虚荣指标**：日活大但没人用的不算

## 候选 + 评估
给出 3 个候选指标，每个评估：
- 定义：精确到公式
- 优点：为什么它是好北极星
- 缺点：什么情况下它会误导
- 适配阶段：哪个阶段最适合
- 替代品：如果不上这个，备选是什么

## 推荐 + 落地
- 推荐的北极星（精确公式 + 截图示例 + 历史 6 个月曲线）
- 输入指标：3-5 个推动北极星的具体动作指标
- 团队看板：北极星 + 输入指标的展示方式
- 切换时机：什么情况下要换北极星

## 写作硬规则
- 拒绝虚荣指标（DAU / 注册量除非能拆解到核心价值）
- 拒绝复合指标（不能用「用户活跃度 = DAU × 30% 付费率」这种）
- 必须可被一个数字描述
- 必须给出 6 个月历史曲线以验证指标可解释过去
- 不写「综合指标」「多维度指标」这种模糊定义

## 自检
- [ ] 是否满足 5 个选定标准
- [ ] 是否可被一个数字描述
- [ ] 是否领先于收入但可被团队影响
- [ ] 是否给出了切换时机
