## 输入
- 产品：{{产品名 + 流量规模}}
- 想验证的问题：{{一个明确的决策}}
- 当前数据：{{基础转化率 + 流量 / 天}}
- 决策阈值：{{业务上多大的差异值得上线}}

## 测试设计
1. **假设**：
   - H0（零假设）：新方案不优于旧方案
   - H1（备择假设）：新方案优于旧方案，提升 ≥X%
2. **变量**：
   - 实验组：{{具体改动}}
   - 对照组：{{现状}}
   - 唯一变量：{{只改一个，其他保持一致}}
3. **核心指标**：1 个主指标 + 2-3 个护栏指标
4. **样本量计算**：
   - 基线转化率：{{X%}}
   - 最小可检测效应：{{Y%}}
   - 统计显著性：95%
   - 统计功效：80%
   - 所需样本量：{{N / 组}}
   - 预计测试周期：{{N 天}}
5. **流量分配**：50/50 或其他
6. **决策规则**：
   - 上线条件：{{达到统计显著 + 护栏指标未恶化}}
   - 放弃条件：{{显著劣于 / 未达预期}}
   - 延长条件：{{未达样本量但趋势一致}}

## 解读模板
- p < 0.05：显著，按规则决策
- p ≥ 0.05 但趋势一致：可能样本不够，延长或换指标
- p ≥ 0.05 且趋势相反：方向错了，停下来重新想

## 写作硬规则
- **必须有明确的决策规则**，不接受「跑跑看」
- 样本量必须计算，不凭感觉
- 主指标只能 1 个，避免「多个指标都提升了」的偶然性
- 必须有护栏指标（防止短期看涨但长期看跌）
- 不在产品大改 / 大促期间做测试
- 测试周期完整（至少覆盖 1 个完整用户行为周期）

## 自检
- [ ] 假设是否明确可证伪
- [ ] 样本量是否计算过
- [ ] 是否有护栏指标
- [ ] 决策规则是否明确无歧义
- [ ] 测试周期是否覆盖完整周期
