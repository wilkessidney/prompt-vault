## 每个竞品的定价拆解
1. **定价模型**：订阅 / 按量 / 一次性 / Freemium / 增值服务
2. **套餐结构**：几个层级 + 每个层级的：价格 + 核心权益 + 目标用户 + 锚定作用
3. **价格心理学**：用到的招数（锚定 / 诱饵 / 损失厌恶 / 社会证明）
4. **续费 / 流失**：年付折扣 / 自动续费 / 退出壁垒
5. **真实 LTV**：用户平均付费金额 + 付费周期
6. **价格敏感度**：哪些用户对价格敏感（流失率）/ 哪些不敏感

## 我方定价建议
- 推荐定价模型（基于赛道 + 用户付费习惯 + 竞品对比）
- 推荐套餐结构（3-4 层 + 每层的核心权益）
- 锚定价与诱饵价
- 上线 90 天的定价验证指标

## 写作硬规则
- **定价数据必须公开可查**（官网 / 应用商店 / 公开报道）
- 不编造内部数据
- 套餐结构给具体价格 + 权益对比表
- 区分「定价策略」和「定价建议」：前者描述现状，后者给方案
- 不建议「免费」除非赛道普遍免费
- 价格建议给具体数字 + 理由 + 验证指标
