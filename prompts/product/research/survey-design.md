## 输入
- 产品：{{产品名 + 用户量}}
- 调研目的：{{NPS / 满意度 / 功能需求 / 用户画像}}
- 触达渠道：{{站内 / 邮件 / 群 / 第三方}}
- 预期样本量：{{N 份}}

## 问卷设计结构
### 1. 问卷元信息
- 标题：明确告知用户这问卷关于什么
- 时长：≤5 分钟（每超过 1 分钟完成率下降 5%）
- 激励：有无
- 隐私：数据用途 + 是否匿名

### 2. 开场筛题（≤2 题）
- 资格题：判断用户是否符合目标画像
- 引导题：进入主题

### 3. 主体问题（≤8 题）
每类问题给具体问法 + 选项设计：
- 单选：互斥 + 穷举
- 多选：明确「最多选 X 项」+ 选项互斥
- 量表：1-5 / 1-7 / 1-10，明确量表锚点
- 排序：≤5 项
- 开放式：≤2 个（开放式问题完成率最低）
- NPS 类：0-10 量表 + 必填开放式追问

### 4. 题目顺序原则
- 简单 → 复杂
- 客观 → 主观
- 一般 → 敏感
- 不让上一题影响下一题

### 5. 选项设计硬规则
- 选项互斥且穷举（MECE）
- 加上「其他」+ 填空
- 量表中性，不带「满意」「不满意」标签
- 顺序随机化（防止顺序偏差）

## 写作硬规则
- **每题单维**：不复合（「你对 XX 的满意度和频次」×）
- 不诱导：不用「大多数人都觉得 XX」之类引导
- 不假设：不用「你使用 XX 时」「如果你使用 XX」（先确认是否使用）
- 中性表述：不用「创新」「卓越」「领先」
- 必要时反向题检测一致性
- 预测试：发布前 5-10 个用户跑一遍

## 自检
- [ ] 时长是否 ≤5 分钟
- [ ] 每题是否单维
- [ ] 选项是否互斥且穷举
- [ ] 是否避免了诱导性
- [ ] 是否预测试过
