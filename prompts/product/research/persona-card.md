你是用户研究顾问。帮我基于调研输出一份用户画像卡。{{产品 + 调研结果}}

## 输入
- 产品：{{产品名}}
- 调研来源：{{访谈 / 问卷 / 数据 / 销售反馈}}
- 用户分层：{{如按使用频次 / 按角色 / 按付费层级}}

## 画像卡结构（每个分层一张）
### 1. 基本信息
- 姓名：{{虚拟名（中文名）}}
- 头像描述：{{职业 / 外貌 / 衣着}}
- 人口统计：{{年龄 / 城市 / 教育 / 收入}}
- 一句话：{{这个人是谁 + 为什么用我产品}}

### 2. 行为画像
- 典型一天：{{日常行为 + 我产品的位置}}
- 使用场景：{{何时 / 何地 / 为什么打开我产品}}
- 使用频次 / 时长：{{具体数字}}
- 使用路径：{{典型流程}}

### 3. 目标与痛点
- 核心目标：{{用我产品要达成什么}}
- 次要目标：{{顺便达成什么}}
- 最大痛点：{{用我产品前后最大的不同}}
- 未被满足的：{{想要但没找到的功能}}

### 4. 决策模式
- 触发购买的：{{是什么让他第一次 / 再次购买}}
- 阻止购买的：{{是什么让他犹豫 / 放弃}}
- 信任来源：{{他相信谁的话（KOL / 朋友 / 同事 / 数据）}}
- 价格敏感度：{{对价格的反应}}

### 5. 媒体偏好
- 信息获取渠道：{{公众号 / 知乎 / 小红书 / 抖音 / 朋友 / 搜索}}
- 内容偏好：{{长文 / 短视频 / 直播 / 图文}}
- 关键影响者：{{关注谁 / 信任谁}}

### 6. 引言
- 直接引用：≥3 句他在调研中说过的话
- 每句引言后说明：这句话揭示了什么

## 写作硬规则
- **每个画像必须有数据支撑**，不写「感觉」「印象」
- ≥5 个用户的引用，不写「大家都说」
- 区分「真实行为」（他实际做了什么）vs「自述偏好」（他说什么）
- 画像卡不超过 5 张（多了失焦）
- 每张画像给具体名字 + 头像描述（不是「用户 A」）
- 引言必须真实，不编造

## 自检
- [ ] 每个画像是否有数据支撑
- [ ] 是否区分了行为和自述
- [ ] 画像数量是否 ≤5 张
- [ ] 引言是否真实可追溯
