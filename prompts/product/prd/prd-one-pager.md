你是 PRD 写作教练。帮我写一份一页纸 PRD。{{功能 + 背景}}

## 输入
- 功能名：{{简短功能名}}
- 提议人：{{PM / 业务 / 用户反馈}}
- 紧急度：{{业务紧急 / 体验改进 / 战略投入}}
- 已有材料：{{用户反馈 / 数据 / 竞品参考}}

## 一页纸 PRD 结构（≤1500 字，2 屏）
### 1. 背景（≤200 字）
- 什么问题：{{用户痛点或业务问题，给数字}}
- 现状：{{当前如何解决，缺什么}}
- 时机：{{为什么现在做}}

### 2. 目标（≤100 字）
- 业务目标：{{1 个，可量化}}
- 用户价值：{{1 个，可感知}}

### 3. 方案（≤400 字）
- 用户场景：{{典型用户 + 典型场景}}
- 核心流程：{{步骤 1 / 2 / 3}}
- 关键决策：{{2-3 个，每个给选项 + 选择 + 理由}}

### 4. 度量（≤200 字）
- 主指标：{{1 个}}
- 护栏指标：{{1-2 个}}
- 验证周期：{{X 天}}

### 5. 范围与不做（≤200 字）
- 在范围内：{{列出}}
- 不做：{{明确不做，避免范围蔓延}}

### 6. 风险与依赖（≤100 字）
- 已知风险：{{列出 + 缓解}}
- 依赖：{{需要谁配合 / 何时可用}}

## 写作硬规则
- **总字数 ≤1500**，不写超过 2 屏
- 每个论断都有数据 / 用户引用 / 竞品参考
- 决策给选项 + 选择 + 理由，不写「我们决定」
- 不写「用户友好」「体验优化」这种无信息词
- 范围明确，避免「以及任何提升体验的细节」
- 风险必须给缓解方案，不只是列出

## 自检
- [ ] 总字数是否 ≤1500
- [ ] 目标和度量是否可量化
- [ ] 范围与不做是否清晰
- [ ] 风险是否有缓解方案
