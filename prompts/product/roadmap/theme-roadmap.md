你是产品规划顾问。帮我做一个主题路线图。{{产品 + 时间窗口 + 核心主题}}

## 输入
- 产品：{{产品名 + 阶段}}
- 时间窗口：{{6 个月 / 12 个月 / 24 个月}}
- 团队：{{规模 + 配置}}
- 战略目标：{{长远愿景}}

## 主题路线图结构
### 1. 战略愿景（≤50 字）
一句话讲清产品长远要成为什么

### 2. 主题（3-5 个）
每个主题：
- 主题名：用问题而非解决方案命名
  - √「让新用户 5 分钟内完成首次价值」
  - ×「添加新手引导功能」
- 主题描述：用户视角的问题描述
- 业务影响：解决这个主题能带来什么
- 度量指标：成功标准
- 时间窗口：解决这个主题的预期时间

### 3. 主题优先级
- 影响力：高 / 中 / 低
- 紧急度：高 / 中 / 低
- 战略对齐：与愿景的关联强度

### 4. 主题下的探索方向
- 每个主题下列出 3-5 个探索方向
- 方向是解决方案的候选，不锁定
- 探索方向给：假设 + 验证方式 + 预期产出

### 5. 不做的主题
明确不做的方向 + 理由

## 输出格式（路线图可视化）
```
Q1: 主题 1 启动 ── 主题 2 启动
Q2: 主题 1 推进 ── 主题 3 启动 ── 主题 2 收尾
Q3: 主题 1 收尾 ── 主题 3 推进 ── 主题 4 启动
Q4: 主题 3 收尾 ── 主题 4 推进 ── 主题 5 启动
```

## 写作硬规则
- **主题用问题命名**，不用解决方案命名
- 主题数量 ≤5 个，太多失焦
- 时间窗口不超过 24 个月，更远会失焦
- 主题下探索方向是候选，不锁定（避免过早承诺方案）
- 度量指标可量化，避免「提升体验」
- 调整机制提前约定（每个季度评审）

## 自检
- [ ] 主题是否用问题命名
- [ ] 主题数量是否 ≤5
- [ ] 每个主题是否有度量指标
- [ ] 探索方向是否候选而非锁定
- [ ] 时间窗口是否合理
