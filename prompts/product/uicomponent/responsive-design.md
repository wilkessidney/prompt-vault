## 响应式设计规则结构
### 1. 断点定义
- 移动：≤640px（手机竖屏）
- 大移动：641-768px（手机横屏 / 小平板）
- 平板：769-1024px
- 桌面：1025-1440px
- 大屏：≥1441px

### 2. 布局规则
- 网格系统：列数 / 间距 / 容器宽度
- 栅格：每页的最大列数
- 容器：最大宽度 / 内边距 / 自适应规则
- 间距：基础间距单位（4 / 8）+ 缩放规则

### 3. 组件适配规则
每个核心组件给：
- 桌面布局：完整功能
- 平板布局：保留核心，省略次要
- 移动布局：精简 + 关键路径优先
- 触控目标：≥44pt / 48dp
- 字号缩放：基准 + 缩放系数
- 间距缩放：基准 + 缩放系数

### 4. 内容优先级
- 关键内容：永远显示
- 次要内容：桌面显示，移动隐藏
- 辅助内容：折叠 / 抽屉 / 弹层
- 内容顺序：移动优先调整

### 5. 交互适配
- 鼠标交互：hover / 右键 / 拖拽
- 触屏交互：tap / 长按 / 滑动 / pinch
- 输入方式：键盘 / 触控 / 语音
- 导航：顶栏 / 侧栏 / 底部 Tab / 汉堡菜单

### 6. 性能
- 图片响应式：srcset / sizes
- 字体响应式：可变字体 / 系统字体
- 资源按需加载：移动端只加载必要资源
- 渲染优化：避免大列表 / 大图片阻塞

### 7. 测试覆盖
- 真机测试：至少 3 个尺寸
- Chrome DevTools：覆盖所有断点
- 浏览器兼容：移动浏览器占比 top 3
- 性能监控：Lighthouse / WebPageTest

## 写作硬规则
- **每个组件都有适配规则**，不只是页面
- 断点基于实际设备数据，不用「常见断点」
- 触控目标 ≥44pt
- 字号缩放基于相对单位（rem / em）
- 性能规则基于 Lighthouse 评分目标
