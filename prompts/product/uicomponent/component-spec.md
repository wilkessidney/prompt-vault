## 组件规格说明结构
### 1. 概述
- 一句话定位：{{解决什么问题}}
- 何时使用：{{典型场景}}
- 何时不用：{{不该用的场景}}
- 相关组件：{{相似 / 互补 / 替代}}

### 2. API（Props）
- 必填 prop：{{name + type + 默认 + 说明}}

### 3. 状态
- 内部状态：{{hover / focus / active / disabled / loading / error}}
- 外部状态：{{受控 / 非受控 / 默认值}}
- 状态切换：{{每个状态之间的切换条件}}

### 4. 视觉规格
- 尺寸：{{size 枚举 + 每个的具体像素}}
- 颜色：{{variant + 每个的具体色值 + 可定制性}}
- 排版：{{字号 / 字重 / 行高}}

### 6. 边界与异常

- 渲染性能：{{大列表 / 复杂内容}}
- 资源占用：{{图片 / 字体}}
- 懒加载：{{按需 / 默认}}

## 写作硬规则
- **每个 prop 都有 type + 默认 + 说明**
- 每个状态都有视觉 + 交互规格
- 键盘交互必须明确（可访问性）
- 边界条件穷举（不写「异常情况」）
- 国际化必须考虑（即使初期不做）
- 给具体像素值，不用「小」「中」「大」

- [ ] 每个 prop 是否有 type + 默认
- [ ] 状态是否穷举
- [ ] 键盘交互是否明确
- [ ] 边界条件是否穷举
