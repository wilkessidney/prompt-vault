生成治愈系（cozy）室内场景。

## 输入
- 空间：{{书房角落 / 咖啡馆 / 卧室 / 阁楼 / 树屋}}
- 时段与天气：{{雨天午后 / 雪夜 / 清晨}}
- 画幅用途：{{壁纸 / 插画 / 游戏 UI 背景}}

## 输出
1. **光的设计**：光源清单（窗光/台灯/壁炉/屏幕光），色温对比（冷窗光 5600K + 暖灯 2700K 的层次），光的形状（百叶条纹/透过玻璃杯的焦散）。
2. **物件清单**：按「热饮/织物/绿植/书/小物」五类各给 2-3 个，物件的「被使用感」（翻开的书/搭着的毛毯/半杯茶）。
3. **氛围要素**：雨声暗示（窗上水痕）、蒸汽（咖啡/汤）、宠物的存在感（尾巴一角/毛毯上的猫窝）。
4. **英文提示词**：cozy interior 完整 prompt（含 soft lighting、warm color palette、detailed props）+ 负面提示词（排除杂乱/冷清/空旷）。
5. **平衡点**：物件密度控制在「丰富但不乱」的清单边界。

**硬规则**：治愈感 = 暖光 + 使用痕迹 + 安全感（半围合的空间感），三者缺一不可。
