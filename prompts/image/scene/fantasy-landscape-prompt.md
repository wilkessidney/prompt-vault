帮我构建奇幻风景场景。

## 输入
- 场景类型：{{浮空岛 / 巨树 / 冰川遗迹 / 异星地貌 / 自定义}}
- 尺度感：{{人的渺小 / 巨物压迫 / 亲密角落}}
- 时间与光：{{黄金时刻 / 极光 / 双月之夜 / 神秘光源}}
- 用途：{{壁纸 / 概念设计 / 插画背景}}

## 输出
1. **地貌逻辑**：给这个「不可能地貌」一个内在规则（悬浮石的引力源/巨树的生态循环），让奇观可信。3 个候选设定。
2. **构图方案**：视线引导（S 型河流/V 型峡谷）、前景锚点（人物剪影定比例）、地平线位置。
3. **光与色**：光源设定、大气透视（远处降饱和）、主色 + 点缀色 hex。
4. **英文提示词**：epic fantasy landscape 完整 prompt（含 scale、atmosphere、lighting 关键词）+ 负面提示词。
5. **系列化**：同世界观 3 张（远全景/中景/特写）的提示词变体模板。

**硬规则**：奇观要有一个「熟悉锚点」（人/树/瀑布）让尺度成立；禁止元素堆砌式随机组合。
