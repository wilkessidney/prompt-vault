帮我设计史诗战争/战斗场景。

## 输入
- 世界观：{{冷兵器 / 魔法奇幻 / 现代 / 科幻}}
- 尺度：{{双人对决 / 小队遭遇 / 千军万马}}
- 视角倾向：{{士兵视角（临场感）/ 全知视角（格局感）}}
- 情绪：{{热血 / 悲壮 / 压抑}}

## 输出
1. **叙事焦点**：大场面也只讲一个人的故事——指定画面主角（受伤的旗手/持盾的士兵），其余是氛围。
2. **景别方案**：
   - 广角全景（格局）：战场地理、阵营色块对撞、烟尘
   - 中景（戏剧）：主角与对手的互动、飞溅物
   - 特写（情绪）：表情/紧握的手/致命一瞬
3. **动态要素**：方向线（冲锋的斜线构图）、飞溅物（雨/泥/火星）、布料与旗帜的运动。
4. **色与光**：低明度基底 + 火光/魔法光源的局部点亮；血与泥土的降饱和处理（避免艳俗）。
5. **英文提示词**：epic battle scene 完整 prompt + 负面提示词（排除摆拍感/干净/正面强光）。

**硬规则**：混乱必须有秩序——所有运动指向叙事焦点；禁止「两边站好人互砍」的静态群像。
