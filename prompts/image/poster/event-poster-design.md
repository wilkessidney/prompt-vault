设计活动海报。

## 活动
- 名称与类型：{{活动名 / 类型（演出 / 展览 / 讲座 / 促销）}}
- 关键信息：{{时间、地点、嘉宾/卖点（按重要度排）}}
- 调性：{{严肃 / 潮流 / 文艺 / 商业}}
- 投放场景：{{社交媒体 / 印刷张贴 / 双端}}

## 输出
1. **视觉概念**：3 个方向（各一句话核心创意 + 适配调性理由），推荐 1 个。
2. **信息层级**：海报上的文字按视觉权重排（主标题>日期地点>副信息>二维码），字号比例建议（如主标题是正文的 6 倍）。
3. **版式骨架**：文字区与图像区的分割（上题下图/中心爆炸/满版图+底部信息条），远看 3 秒读到什么。
4. **生成提示词**：完整英文 prompt（poster design + 风格 + 构图 + 负空间留给文字）+ 负面提示词。
5. **落地提醒**：AI 生成图中的文字不可靠——排版建议在 {{Figma / PS}} 里做，提示词只生成背景/主视觉。

**硬规则**：海报先解决「3 米外能不能读出主信息」；字体提示词要指定情绪而非具体商业字体名。
