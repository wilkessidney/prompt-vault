设计一张以文字本身为画面的字体海报。

## 输入
- 主文案：{{核心文字（1-10 字）}}
- 语境：{{为什么做这张海报}}
- 情绪：{{希望传达的情绪}}

## 输出
1. **字义可视化**：文案的语义里藏着什么视觉动作？（「高」字拉长 / 「乱」字错位 / 「静」字留白包围）给 3 个字义→字形联动方案。
2. **字形选择**：匹配情绪的字体类型（粗黑体的宣言感 / 宋体的文气 / 手写的温度 / 等宽的机械感），每类适配场景一句话。
3. **编排方案**：字号对比（≥4 倍差才有戏剧性）、字间/行间张力、文字与画面边缘的关系（出血/居中/贴角）。
4. **点睛手法**：笔画替换（部件换成图形）、遮挡（字被裁切后仍可读）、材质（锈/水/织物）——选 1 个克制使用。
5. **英文提示词**：typographic poster 完整 prompt（AI 只做背景质感，文字后期排）+ 手工排版的执行要点。

**硬规则**：一张海报只允许一个聪明点子，第二个就是噪音；中文提示字义联动时必须可读性优先。
