## 作品
- 类型：{{科幻 / 悬疑 / 文艺 / 动作 / 恐怖}}
- 一句话故事：{{故事梗概}}
- 主角与核心意象：{{主角设定 / 贯穿意象}}

## 输出
1. **类型语法**：该类型片的视觉惯例（构图/色调/字体气质），如恐怖=低明度+面部局部的暗示、科幻=人的渺小与结构感。
2. **概念方案 ×3**：
   - A 主角主导（character-driven）：大特写的情绪
   - B 意象主导（concept-driven）：核心隐喻物
   - C 群像/场景主导：世界观一瞥
3. **深化 1 个**：色彩脚本（3 色 + 情绪对应）、光比、景深、主角姿态的叙事含义（背影=未知/面对=对抗）。
4. **英文提示词**：movie poster style 完整 prompt（含 typography space 预留说明）+ 负面提示词。

**硬规则**：海报要「藏一个钩子」——观众看完海报产生的一个问题，说明这个钩子是什么。
