帮我设计个人品牌标识。

## 我是谁
- 姓名/网名：{{名字}}
- 职业身份：{{设计师 / 开发者 / 写作者 / 自由职业多面手}}
- 想给人的印象：{{专业可靠 / 有趣 / 审美好 / 极客}}
- 使用场景：{{简历/作品集 / 社交媒体头像 / 个人网站 / 全部}}

## 输出
1. **符号策略**：个人标识三条路——
   - A 纯字标（名字即品牌）：字体气质怎么选
   - B 名字缩写/首字母：负空间或笔画变形藏一个与职业相关的彩蛋
   - C 抽象符号：代表工作方式的图形（写作者的笔锋/开发者的光标）
   分析哪条最适合我，为什么。
2. **推荐方案细化**：字形/几何描述、单色与反白版本、头像场景的圆形裁切适配（关键元素居中在安全区内）。
3. **中英文适配**：名字若有中英文双版本，两者的搭配关系（并列/主次/只用一个）。
4. **英文提示词**：personal monogram logo 完整 prompt + 负面提示词。
5. **防过时**：什么设计决定会让它 3 年后显得土（跟风样式清单）。

**硬规则**：个人标识必须「签名级简洁」——能 30 秒手写出来最好；头像场景优先于印刷场景。
