设计 Q 版（chibi）角色。

## 输入
- 原型：{{已有角色描述 / 或全新设定}}
- 头身比：{{2头身 / 3头身}}
- 风格：{{日系赛璐璐 / 厚涂 / 平面矢量}}
- 用途：{{表情包 / 周边 / 游戏素材}}

## 输出
1. **Q版化规则**：
   - 头：眼占脸部比例拉到 {{50%+}}，瞳孔高光双层
   - 身：四肢缩短成藕节，手脚简化成圆形
   - 特征夸缩：原型的标志性元素保留并放大（帽子/武器变成比例失调的萌点），可删细节清单（衣服褶皱/复杂纹样）
2. **表情系统**：基础 6 表情（喜/怒/哀/惊/羞/困）的变化点（眉毛角度/嘴形/附加符号汗滴）。
3. **配色**：明度整体 +1 档、饱和度 +10-15% 的「Q 版滤镜」；主色 hex。
4. **英文提示词**：chibi character 完整 prompt（含头身比、style、clean lineart）+ 负面提示词（排除写实比例/恐怖谷）。
5. **系列延展**：动作变体（跳/躺/比心）的提示词模板。

**硬规则**：Q 版的萌来自「比例失调+特征保留」的平衡——删掉标志性特征就成了任何宝宝；眼睛必须有高光。
