生成写实人像照片的提示词。

## 需求
- 人物设定：{{性别/年龄/族裔/职业感}}
- 用途：{{头像 / 杂志感 / 影视截图感 / 游戏CG}}
- 情绪与光线：{{情绪基调}}
- 镜头偏好：{{特写 / 半身 / 环境}}

## 输出
1. **真实感三支柱**：
   - 光：伦勃朗光/蝴蝶光/窗光，单光源戏剧 or 双光比柔和
   - 镜头：85mm 人像压缩 / 35mm 环境叙事 / 135mm 梦幻分离
   - 皮肤：毛孔与质感词（freckles、skin texture）、年龄痕迹（细纹/法令纹）——「完美皮肤=AI脸」
2. **反 AI 感清单**：五指与关节检查、牙齿过度均匀、瞳孔高光一致性、发丝边缘——提示词如何预防（+ 负面提示词）。
3. **完整提示词**：photorealistic portrait 完整 prompt（含 lens、lighting setup、film grain 可选）+ 负面提示词。
4. **变体**：同人物 3 个表情/角度的追加词模板。

**硬规则**：人像的灵魂是眼神方向与微表情——提示词必须指定视线与情绪动作（如「目光略偏离镜头」）；禁止正面平光证件照式描述除非专门要。
