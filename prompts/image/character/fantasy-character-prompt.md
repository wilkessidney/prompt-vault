帮我设计奇幻角色。

## 输入
- 职能定位：{{战士 / 法师 / 盗贼 / 圣职 / 自定义}}
- 种族/文化原型：{{精灵 / 北欧 / 东方 / 沙漠民族 / 自定义}}
- 性格与背景一句话：{{角色故事梗概}}
- 视觉重点：{{战斗感 / 神秘感 / 华丽 / 落魄}}

## 输出
1. **设计逻辑**：职能 → 装备（战士重甲的防护逻辑/法师轻袍的施法逻辑）；文化 → 纹样/材质/色彩（有地理依据）；背景 → 磨损/战利品/个人物件（斗篷上的补丁说的是流浪）。三者各给 3 个具体设计点。
2. **剪影测试**：这个角色的剪影是否独有（兵器形状/头身轮廓/服饰极端化），描述其剪影特征。
3. **色板**：主色 2 + 点缀 1，hex；文化依据一句话。
4. **英文提示词**：full body character 完整 prompt（含 character design sheet、 costume details、three views 可选）+ 负面提示词。
5. **动作变体**：战斗待机/施法/休闲三个姿势的提示词补充段。

**硬规则**：装备必须「能穿得上脱得下」（有扣带有绳结）；禁止性感化无意义的裸露设计。
