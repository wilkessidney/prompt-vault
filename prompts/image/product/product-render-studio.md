- 材质：{{瓶身/主体材质（磨砂玻璃 / 铝合金 / 陶瓷）}}
- 卖点：{{最想突出的卖点}}

## 输出
1. **画面方案 ×3**：
   - A 纯棚拍白底（电商主图）：柔光箱位置、倒影板、投影控制
   - B 生活方式场景（详情页）：场景道具、前景虚化、氛围
   - C 创意概念图（品牌海报）：超现实手法 + 卖点隐喻
2. **材质打光要点**：针对该材质的光线策略（透射/反射/哑光各怎么打），一句话摄影原理。
3. **英文提示词**：三方案各一段完整 prompt（含 lens、lighting、composition、mood 关键词）+ 负面提示词。
4. **细节检查**：label 朝向、logo 清晰度、材质接缝——AI 渲染最常翻车的点及提示词对策。

**硬规则**：主图方案必须符合电商平台白底规范；卖点必须成为画面的视觉焦点而不只是道具。
