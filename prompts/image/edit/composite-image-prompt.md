帮我做图像合成（composite）创意与执行方案。

## 创意输入
- 想合成的画面：{{想要的最终画面描述}}
- 已有素材：{{手头有什么素材}}
- 用途：{{创意海报 / 概念验证 / 娱乐}}

## 输出
1. **创意框架**：合成的新鲜感来自「尺度错位/材质错位/语境错位」，我的创意属于哪种、怎么强化。
2. **素材清单**：需要哪些图层（背景/主体/前景/特效），每层的拍摄/生成规格要求（分辨率、方向、光照方向）。
3. **统一性三关**：
   - 光：所有素材的光源方向/软硬/色温必须一致（先定主光再选素材）
   - 透视：视平线和镜头焦段要匹配（广角背景配长焦主体=假）
   - 边缘：抠图边缘的处理等级（硬边/环境光渗色/发丝的混合策略）
4. **AI 生成路线**：直接用生成模型的完整英文 prompt（把合成意图描述为单一画面）vs PS 手工合成，各自适用条件。
5. **自检清单**：影子（每个人都有影子吗，方向对吗）、反射、空气透视、噪点/颗粒统一。

**硬规则**：合成的成败 90% 在光照统一；阴影方向错误是最常见的穿帮——输出里必须有影子设计说明。
