- 问题：{{曝光 / 色偏 / 杂乱 / 皮肤质感 / 构图}}
- 成片用途：{{社交媒体 / 商业交付 / 比赛}}

## 输出
1. **诊断先行**：先读直方图——高光死白？暗部死黑？色温偏 {{暖/冷}}？确定「保什么牺牲什么」（如保天空细节则地面欠曝另处理）。
2. **调整顺序**（破坏性从低到高）：镜头校正 → 白平衡 → 曝光/对比 → HSL 分区调色 → 局部（渐变/径向/画笔）→ 锐化降噪 → 最终裁切。每步做什么、到什么程度算够。
3. **皮肤修饰规范**（如人像）：频率分离思路、瑕疵修复「修形不修质」原则、避免塑料脸的度。
4. **色彩方向**：给 2 个调色方向（各自色彩逻辑：阴影加青+高光加暖的胶片感 / 高明低饱和的日系），含具体 HSL 参数起点。
5. **交付检查**：不同尺寸预览（手机上看会不会太暗）、导出参数（sRGB/质量）。

**硬规则**：修图目标是「像没修过」；每步调整必须可回退；禁止一上来就拉清晰度。
