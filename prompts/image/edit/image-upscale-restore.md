帮我规划老照片修复。

## 照片情况
- 年代与损伤：{{年代 / 划痕 / 泛黄 / 破角 / 模糊 / 黑白}}
- 修复目标：{{恢复原貌 / 适度增强 / 上色 / 全套}}
- 重要性：{{家庭纪念 / 收藏级}}

## 输出
1. **修复优先级**：损伤清单按「信息抢救」排序——先救结构（破角/撕裂），再清表面（划痕/污渍），最后增强（锐化/上色）。为什么顺序不能反。
2. **分层策略**：
   - 结构层：破损区域的补全原则（从同照片采样而非脑补细节）
   - 色调层：泛黄校正、黑白对比度重建
   - 细节层：适度锐化，接受老照片的物理局限（不要幻想出不存在的高清）
3. **上色方案**（如需要）：时代考证提醒（那个年代的服饰/材质常用色）、上色的「真实感」原则（低饱和/材质影响颜色）。
4. **工具路线**：损伤分级对应的工具（小划痕修复画笔 / 大面积内容生成填充 / AI 上色的检查点）。
5. **伦理边界**：修复 vs 篡改——哪些「顺手美化」（磨皮/改表情）不该做，家人要的是那张旧照片。

**硬规则**：家庭纪念照以「像本人」为最高优先级；AI 生成部分必须逐处人工核对五官；保留修复前原件。
