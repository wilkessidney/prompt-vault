为我的图像/视频设计调色方案。

## 素材
- 内容：{{画面内容}}
- 现在的问题：{{平淡 / 色脏 / 想要风格化}}
- 目标风格：{{电影感橙青 / 复古胶片 / 冷冽北欧 / 高饱和糖果}}
- 工具：{{Lightroom / DaVinci / PS}}

## 输出
1. **色彩逻辑**：这个风格的核心公式——阴影/中间调/高光各偏什么色、明度关系（如电影感=阴影偏青绿+肤色偏橙+整体高对比），为什么成立（视觉心理/胶片化学溯源）。
2. **参数起点**：色温/色调偏移、曲线形状（描述 RGB 各通道怎么弯）、HSL 里肤色保护策略。
3. **肤色特区**：任何风格化都不能毁肤色——肤色的目标区间与保护手法。
4. **风格强度控制**：从「淡淡的」到「满格风格化」的 3 档参数差。
5. **反向校验**：调完后怎么知道对了（对比参考图/直方图特征/只看黑白稿查明度）。

**硬规则**：调色是「系统性偏移」不是「随机拉杆」——输出必须能解释每个参数为什么这么设；禁止饱和度全图暴力拉高。
