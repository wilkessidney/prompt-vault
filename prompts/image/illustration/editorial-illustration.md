为下方文章设计社论插画（editorial illustration）。

## 文章主旨
{{文章核心观点（1-3 句）}}

## 要求
- 用途：{{杂志配图 / 公众号头图 / 报纸评论版}}
- 风格倾向：{{极简几何 / 手绘线稿 / 拼贴 / 3D 概念}}
- 限制：{{可否出现人脸 / 品牌元素}}

## 输出
1. **概念发想**：5 个视觉隐喻方向，每个——隐喻逻辑（A 代表 B，为什么成立）+ 一句话画面。按「观点锐度」排序。
2. **最优方案深化**：选 1 个展开：构图、视觉元素清单、色彩情绪（3 色以内）、负空间怎么用。
3. **英文提示词**：可直接用于图像生成的完整 prompt + 负面提示词。
4. **避雷**：这个主题最容易画成的俗套（ cliché ）是什么，怎么绕开。

**硬规则**：社论插画要有立场，不是配图装饰；禁止「科技=发光大脑」「时间=沙漏」级别的陈词滥调，除非给出颠覆性用法。
