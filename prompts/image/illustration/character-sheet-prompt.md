## 输出
1. **视觉转译**：性格 → 视觉元素映射表（如「谨慎」→ 收肩/贴身衣物/小步幅），证明设计有依据。
2. **角色描述模板**：外貌（体型/脸型/发型/瞳色）+ 服装（材质/颜色/磨损度暗示经历）+ 标志性物件 ×3（跨画可识别的锚点）。
3. **生成提示词**：character sheet 布局说明（三视图 正/侧/背 + 2 个表情 + 关键道具特写）+ 风格关键词 + T-pose/A-pose 说明 + 负面提示词。
4. **一致性方案**：后续画该角色其他场景时的锚点清单与提示词模板。

**硬规则**：标志性锚点必须「非全身照也能认出」级别；颜色给出具体色相而非「蓝色」。
