## 环境
- 软件/渲染器：{{Blender+Cycles / 其他}}
- 观察距离：{{特写 / 中景 / 远景}}（决定细节密度）
- 真实感要求：{{照片级 / 风格化}}

## 输出
1. **材质分析**：这个材质的物理构成（基色来源/粗糙度变化规律/法线细节来自什么几何尺度）。
2. **贴图策略**：哪些通道用程序化（噪声/噪波+颜色渐变分层），哪些必须手绘或照片。各贴图分辨率建议。
3. **节点树步骤**：分步描述节点连接（Base Color → BSDF 各接口），关键参数（噪声 Scale、渐变断点）给值。
4. **做旧分层**：边缘磨损、污渍、划痕分别用什么技巧（点纹+法向朝向遮罩等），可控性强。
5. **快速调优**：出图后最可能要调的 3 个参数。

**硬规则**：粗糙度贴图比颜色贴图更重要——写实感 70% 来自粗糙度变化；禁止只调 Base Color。
